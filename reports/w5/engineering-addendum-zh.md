# 附录 C W1 至 W5 工程集成

## C.1 目的与证据版本

本附录记录审定研究报告之后的工程工作。原五章研究正文、研究图、数值表、公式、参考文献及贡献说明均予保留。W1 测量等待链路，W2a 呈现其状态，W3 减少回放准备工作，W5 将选定修复集成为可分发候选。两次 W4 试件均未留存。拟议应用交付版本为 v1.1.0，内嵌 Python 库仍为 0.1.0。本版是本地待审候选，尚未发布，也没有通过负责人本人操作的 E12 验收。

工程上的主要判断是：回放准备可以减量，同时保留所采用的计划及其证明。原 W3 结果支持留存这一路径。W5 检查集成实现与交付入口，其功能检查不构成新的四组性能估计。排程计算速度与 ADAPTIVE、EDD 的产品签收时间比较属于不同结果。五种固定情景配对中最终签收时间未改善的研究结论保持。

## C.2 各阶段实际形成的证据

W1 记录的 CPU 初排和重排构建时间分别为 84.065 s、94.001 s。三次存档首次通过独立核验并可投影分别用时 18.599 s、18.996 s、18.814 s。这些观测将较大等待定位于回放和独立核验，具有各自的进程与输入标识，不是 W5 封包的新计时值。

W2a 区分排程中、等待独立核验、可用和失败。重排期间，工作台保留上一已独立核验的甘特层，并在候选版本旁标明旧计划版本与源龄。实际观测和心跳各自保留含义。只有任务、运行、epoch 和已核计划引用一致时，结果才能替换当前图。有限修复还保留计划引用失败时已接受的业务回执，拒绝新任务开始后迟到的旧结果，并在失败时固定等待耗时。

STOP 继续使用原控制信封。请求发出、持久受理、保存和实际工作进程退出分别显示。响应为 UNKNOWN 时可以查询原 STOP 标识。缺失信封的恢复必须由用户显式操作，并保持原字节身份，不增加第二次已接受的 STOP。原五秒陈旧禁写继续生效。历史 W2a 的 Python 与前端检查共 128 项通过；其三组本地 Qt 测试各有 40 个样本，输入、桥接和阶段呈现延迟的 p95 分别为 59.6 ms、45.5 ms、164.8 ms。这些数字属于该次 W2a 检查，不作为 W5 的新延迟资格结果。

选定 W3 路径只共享已通过结构检查的不可变配置、状态、事件及其子记录。事件列表、工序与路由字典、业务请求、目录优先级及执行状态保持预览私有。后端种子仅在配置对象、运行和 epoch 相同时复用，每次调度仍绑定当前观测。只有配置、优先级输入和请求顺序不变，才复用优先顺序。几何准备保留原障碍顺序及原线段相交判定，包括支承移动和碰撞拒绝。

较早的隔离 W3 候选完成四组实际 CPU AB/BA 配对，共八次运行。改单提交至 APPLIED 且独立核验可投影的配对中位减少 17.331061%；扣除执行与因果审计后的净回放减少 26.501367%。八次运行均保留原 STOP、最终保存与工作进程退出 0。后续审阅发现调用依赖隔离、坏证据拒绝不足两项问题。有限修复通过 20 项专项及一次正常 CPU 链。四组数字继续绑定较早的受测候选，修复版和集成版没有替代它的新四组估计。

W4 的私有结构校验缓存将固定边界至保存从 35.900 s 增至 36.746 s，净回放从 18.697 s 增至 18.968 s。第二次试件复用排除集合外几何，两组 AB/BA 的保存端点和净回放配对中位分别增加 2.770%、3.660%。两次不留存的决定和失败记录均保持，W5 未合入这些缓存。计划与证明一致并不等于获得性能收益。

## C.3 集成实现与独立检查

W5 将实验性源码改写包装器替换为正常软件包模块。每次预览独占种子、优先级缓存和几何准备。嵌套调用或异常退出后恢复上下文内的几何绑定，并发预览不替换公共规划函数。执行与因果审计显式离开回放几何作用域，走原几何路径。没有安装 W4 缓存。原事务、事件、计划采用及 STOP 所有者保持。

固定 L1 v2 的边界为目录代次 1、revision 177、事件数 177、仿真时间 0.36948611111111135 h。集成版计划 SHA-256 为 63b2ceacada7cc79d56b679b518576da1d3f3d0b29c8aa59d848abdee39a1733；解压证明 SHA-256 为 db4c69f5b88e2513c398d031afc65ae626c7f06513680faed22ed4d25bbaa4d7。二者均与原固定边界记录精确一致。这验证了该输入下的等价性，不是新的现场速度结果。

## C.4 候选操作与原路径回退

完整解压 Windows 包，保持 HRC-Workbench.exe 与 app 目录相邻后启动。包内含 Python、Qt WebEngine、排程组件和只读存档。可在“启动配置”选择单产品 SR-W1 CPU 会话。初排期间显示等待；改单期间保留上一已验证计划，待新计划独立核验通过后切换。使用“安全停止”，等待持久受理、保存完成和实际工作进程退出后再关闭工作台。保存的会话以只读方式重开，不能授权新业务写入。

启动前设置 P051_PREVIEW_REUSE=0，可使用原完整复制、原几何和无种子复用的 Python 准备路径。P051_WAIT_FEEDBACK=0 关闭新增等待提示。原核验、写保护和 STOP 处理继续生效。已发布 v1.0.1 包与旧标签作为前一交付保留，候选不会覆盖它们。

可选原生三维使用另行安装的 Isaac Sim 和 PowerShell 7，结果目录须仅含 ASCII 字符。W5 原生检查限定于新建本机合成 USD 场景、SyntheticReceiver 和私有测试会话。ORDER_UPDATE 只修改仿真数据，STOP 只结束并保存该本机仿真。不连接真实工厂设备、PLC、机器人控制器或外部订单系统，不改变 SDK、驱动或系统设置。本机仿真采用 900 s 墙钟预算，另留退出收尾时间。无法证实启动边界时跳过该入口并如实登记，不扩大连接范围。
