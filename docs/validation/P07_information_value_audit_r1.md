## 关键证据与可用的新信息

**方法收益。** 45指标单元中43严格为0，1差值为7.105427357601002e−15，1为U总暴露−0.001012943750F·h（−0.00041865%）。数值噪声筛查采用abs1e−10/rel1e−12，仅分类、不改原值。进一步按产品、人员、人员×活动及运输对齐检查：五情景产品数值结果和运输数值没有可分辨的方法差；人员差只在U的Lop/Lrig/Lsig，各减少约0.000337648F·h，WAIT/WORK暴露变化相抵后构成该净差。不能通过另选一个图形制造普遍优势。

**准时率饱和。** 全0仍是应报告的未达标事实。两方法各有9个未取消产品已接收，全部迟交；迟交时长123.859–363.859h提供严重程度信息。它是对原预定准时率的解释性补充，不重设交期或取消零结果。C的1取消/1接收与其他情景2接收不能同排比较成“更快完成”。

**模式机制。** 正常条件H→HR支路人时12.755→4.036（−68.35%），全员共同窗暴露−3.48%，整单末次接收仍531.859h；高初始疲劳下支路12.719→4.032（−68.30%），全员暴露−4.61%，末次接收553.930→531.859h。配置比对一致，实际支路模式/阶段不同。这比三幅未解释的原值柱更能说明局部节省怎样与全局结果并存。HR两格复用N/H EDD；模式对照不等于自适应策略优于EDD。

**事件响应。** E20同一r14急单登记至首次实际生产动作24.377826h，两个普通产品分别52.970826/120.879082h；采用安排已在登记的相同仿真时刻形成。截止387.732463h，仍仅1件接收，急单迟交下界290.731566h。第一实际非服务STARTED可含搬运，不能改称加工工时；计划采用不等于实际执行。

**暴露形成。** N实际生命周期WAIT占可用人时91.06%、贡献累计暴露68.98%。模型中WAIT正向积累0.02F/h，REST/班外恢复0.2F/h；应解释模型活动归属，而非把面积归为纯作业劳动。N/H配置仅15个initial_f从0.2到0.6，新增暴露63.806210F·h中的99.02%在首24h。不能由这些归属直接断言现实生理规律或生产瓶颈。

**动态与取消。** 两个动态案例各13人的分母相同，其余3个例外才是重点；8组可保留32个人员身份与加权分母。所有到岗定义时刻均0，当前数据不能演示非零时刻新人到岗的量化效果。取消两运行实物/已耗账一致，每次28lot/STEEL3.318t退回，已耗0.7473425人时及96.1m运输等；应展示这份资源账及零残留状态，而非把稀疏散点扩成整页。
