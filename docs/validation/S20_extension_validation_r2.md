## 来源、独立性与限制

D/B只在显式CPU选项启用；legacy分数与默认观察路径保留。候选验证仍要求独立执行和因果重建；实际生产账与假想模型账/派生人因评价账分开。普通实际审计拒绝模型边界；投影保存后独立重建不重新搜索。实际安全盾只接受/拒绝原提案，无拒绝后重搜。

源代码本轮有两处显式接入和三个新包内模块，不声称与旧S19B完整链捕获源码字节相同。旧Kit/桌面证据保持原身份，新的扩展没有新Kit验证，正式输入明确CPU。未取得工业G2；合成F/工时/质量与接收不升级工业事实。S19B已接受限制不重启修复，支承通过不再反复。

B基线从复用A修订为16条同公共采样机制的专用零扰动运行；因此正式规模620→636。这是实现期消除信息更新机制混淆的设计修正，全部新增正式行仍未执行，随r2统一冻结审阅。有限设计/有限种子只作登记域的描述性比较，无总体p值或虚构置信区间。
