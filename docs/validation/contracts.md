# S06 本地契约检查摘要

2026-10-01；候选 `S06-20261001-r2`。本页只记录本地指定检查，不代表人工验收或远端 CI。

统一入口 `uv run --locked --no-editable python scripts/check.py` 检查版本/锁、Ruff、unittest、环境一致性、sdist→wheel 构建及独立 wheel 环境。契约测试同时在项目安装与独立安装中执行。原七项安装/回调检查保留；契约模块覆盖下表。最终为 41 项测试（34 项 S06 加原七项），在项目和独立 wheel 各通过一次；输出摘要绑定本步审阅包。

| 验收内容 | 检查证据 |
| --- | --- |
| 严格数据边界 | 错误版本、未知/缺失字段、重复 JSON 键、bool 冒充数字、非有限/溢出/负数、无效 ID 均拒绝 |
| 引用、DAG、资格 | 未解析订单/模式/元组/物料引用，工序及阶段循环，人员技能不足、机器人不可达、设备/夹具错站被拒绝 |
| 工艺和物料 | 非法模式、缺少 HR 资源、零准备成本、错误活动/取消边界、物料多重领取、错误缓冲类型、缺运输和接收槽不足被拒绝 |
| 状态及 restore | 无原准备的 restore、错误编号/倍率、无效/错站准备上的机器人 work、故障仍有效的准备、超 cap 或未来完成、错误剩余量被拒绝 |
| 信息分离 | 未观察订单不进入规划投影；更改其交期不改变可见输入；未来时间戳/隐藏字段、遗漏 K_t、不当实际完成/预测字段被拒绝 |
| 计划和评价 | 组内改人、Q 不匹配、运输/加工目标不一致、非正时段、缺失 D 预算预测、错误共同窗口/终止状态被拒绝；窗外取消不改离线集合 |
| 序列化与发布资料 | 两份配置与全部消息往返语义相等、规范输出稳定；生成示例和 Schema 与源码逐字节一致；公开材料、差异与旧基线另作封包核对 |

首次本地尝试出现旧安装包缺少新模块、可空 Annotated 类型识别遗漏及静态格式问题；已修复并保留原诊断。没有改写 S05 历史证据或复跑旧工具覆盖其输出。

这些是静态契约、快照约束和接口投影检查。它们不验证跨时刻故障/取消/改派状态机、疲劳积分、执行可行性、真实观测授权、调度器非预见性、仿真、Isaac 闭环或性能；S07 及后续未启动。Schema 生成一致性也不等于用外部 Schema 实现重新验证所有语义。未改变运行依赖、锁文件、工作流或既有规格；远端两平台 CI 待本步批准推送后核验。

r1 封后自查发现运行清单的通用 ID 类型拒绝数字开头的 Git 哈希；r2 改为要求完整 40 位十六进制修订号（planned 结构示例可用明确占位），新增数字开头哈希、移动分支名和终止状态占位的检查。r1 原快照保留，未发布。
