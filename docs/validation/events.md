2026-10-01；治理版本 0.10.0。验证对象为 [S08 规则](../model/events.md)，不是完整生产仿真或算法实验。

## 实际检查

标准入口 `uv run --locked --no-editable python scripts/check.py` 检查 Ruff、格式、依赖锁、项目测试、构建 sdist/wheel，并在独立环境安装 wheel 后重新执行同组测试。源码变更后显式重装非 editable 包，避免旧构建缓存。最终测试数为 126：原 80 项保留，新增 29 项事件测试及 17 项观测测试；两个环境各执行 126 项，不重复计为 252 项不同测试。

| 验收问题 | 证据 |
| --- | --- |
| 同刻可复现 | 五类事件的全部 120 种排列排序一致；外生批次逆序结果一致；完成优先、零剩余未完成拒绝 |
| 故障重做/续作 | CUT/WELD.work 失效；其他加工、运输及 restore 保留剩余量/倍率；重复故障不重复损失，修复不重启 |
| 取消保留成本 | F/E、绑定、锁、物料和实际到库事实保持；准备、work、handoff、五运输阶段逐类边界核对 |
| 清场与故障 | failed work 的 release_allowed 两种情况；吊机不可绕过；已 rig 目标预留保留，完成 preposition 可撤空预留 |
| 准备与 restore | 阶段间故障失效、再定位成本和序号、拒绝嵌套/取消/无原准备，重做重新取样 |
| 授权观测 | 字段独立授权、采样与接收时间、乱序交付、零时取消、部分帧未知、休息不可用、事件 ID 授权 |
| 非预知性 | 替换未来故障/取消、隐藏订单属性及未授权人员/故障真值，当前 PlanningInput 保持相同；确定性消费者见证不变 |
| 随机配对 | 相同稳定身份逆序调用仍一致，世界/观测/加工流与尝试号区分 |
| 既有契约与历史 | 原 S05 样本、S06 消息/Schema/样本及 S07 数值源文件保留；标准测试继续检查旧样本同源生成 |

本地完整命令输出、诊断、逐文件摘要和旧证据保全记录随审阅包在本地留存，不进入公开文件。远端 CI 尚未执行，本地通过不能预写为本轮远端成功。

## 开发中修正与限制

首轮 Ruff 指出新代码中的含混单字母变量和导入排序，已改正并保留诊断。新增测试初次通过后，AI 辅助代码复核发现依赖集合过宽：来源站在 rig 后仍影响 move，feed 在 setup 后仍影响 work。修正为当前阶段依赖，并加入反例；这是本地初版修正，不改写旧发布事实。另明确浮点净加工完成边界，避免有理数重算将声明的浮点整段时长误当越界；疲劳 cap 检查没有放宽。

状态由手工构造，局部转换要求调用方提供已推进到当前时刻且物理事实真实的快照。测试不证明完整资源获取、历史合法性、全部物料清场、任意输入正确性或真实调度器非预知性。当前确定性消费者仅为接口见证；真实调度器、执行日历、进程隔离、噪声模型和双后端集成尚待后续步骤。参数及安全锁止继续是合成、项目选择、未校准模型，不赋予医学或工厂认证解释。
