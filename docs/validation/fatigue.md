80 项 unittest 在两个环境分别通过：保留原 54 项，新增 26 项 S07 测试；不重复计作 160 项。S06 生成文件一致性仍由原测试覆盖；未增加运行依赖或更改 CI 工作流。

| 检查组 | 核对内容 |
| --- | --- |
| 逐段方程 | 五种非休息活动、零负荷、异质恢复、零时长、既有积分保留、输入不可变 |
| 休息边界 | 未触零、恰触零、越过零、初始为零、整窗休息和分段不变性 |
| 严格合法域 | 非有限/非法输入、数值溢出、共同 cap、恰在 cap、一个浮点间距的超限、先超限后休息不能洗去违例 |
| 等待保护 | 首次 cap 接触、返回时界可积分而下一个浮点时长超限、正休息、休后仍不够时继续休息 |
| 工时与进度 | 阶段起点取样、κ=0、HR 单一时长、非敏感阶段、实例工时覆盖、续作原倍率、重做新取样、错误剩余量和 sample/倍率拒绝 |

## 失败与修正

首次标准入口因新增文件格式不合 Ruff 而失败；格式化后测试发现三处共用测试夹具错误地猜测 Q 名称，以及一处超小超限在浮点端点相加后被舍入掩盖。夹具改为按模式资格集及 worker_id 选择；cap 判定增加对输入二进制数的精确有理比较。随后标准入口 77 项通过，再加入时界、restore 取样边界和整窗休息三项测试，最终 80 项通过。

原失败输出和本轮完整执行记录保留本地，不覆盖或公开原始日志。初次命令执行器环境初始化失败，后通过受审查的 PowerShell 7 执行方式完成；此项没有造成仓库修改或改变 shell 选择。旧快照、样本、批准、回执和历史证据另外按逐文件摘要核对。
