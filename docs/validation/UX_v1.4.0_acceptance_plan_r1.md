## 无桌面验证

- 前端纯函数：时间区间真实性、当前生产定位、多选/清空/无映射、旧计划与真实执行区分、请求参数及回执。
- 后端专项：计时封装的可信类型边界、未知/可变对象回退、回放隔离、缓存排除项和障碍顺序、独立审计保留、截图身份/摘要/路径与布局预算。
- 实际生产前端离屏渲染：1280×720、1366×768、1920×1080；中英双语首页、配置、双图、急单确认/等待、自检、结束状态。夹具与真实原生会话明确区分。
- 固定原 v1.3.0 急单锚点；预热后五组成对旧/新路径，交替顺序、进程隔离。核对计划 SHA、解压证明 SHA、完成时间、真实台账不变，记录阶段时间及峰值内存。只报告实际样本，不把 CPU 回放当原生端到端成绩。
- 确切候选的完整源码与隔离 wheel 回归，原测试身份保留。旧字节契约按原路径和摘要迁移到历史副本；不弱化原断言。
- 编译便携入口，核对源码/wheel/sdist/运行包绑定，先形成原生验收用候选；最终交付包在原生修复与验收完成后重新生成。

## 获批后的集中原生验收

| 项目 | 实际操作与证据 | 通过条件 |
| --- | --- | --- |
| 启动/自检 | 从新版便携入口配置与启动，保留检查结果、PID、来源摘要 | 本轮确切候选，首帧与已验证计划真实到达 |
| 点选/框选 | 真鼠标点击人员、设备、物料；空白清空；拖框；Shift/Ctrl；重选 | 原生输入计数、USD 路径、业务 ID、工序和双图高亮一致；不能用程序化选择替代 |
| 输入隔离 | Alt 相机、滚轮缩放；悬停与菜单、Qt/Kit 焦点切换 | 选择不意外移动相机，不修改生产位置/物理/业务状态 |
| 尺寸/DPI | 默认、最小客户区、放大布局；获准显示环境内的缩放场景 | 不串点、不遮挡；两图满足最小操作空间；未覆盖显示器条件明确列出 |
| 工单与急单 | 普通单、改交期/优先级、急单提交到采用；选择关联对象 | 回执、计划、执行、场景分别可追溯；记录总等待和分段时间，不虚构新产品已开工 |
| 人员/设备 | 到岗、离岗/缺勤与返回、故障与维修 | 类型约束、请求序号、实际生效与场景对应；保留不能安全触发项的原因 |
| 计划阅读 | 当前生产、全程、所选、搜索/筛选、旧新对比、表格与键盘 | 时间值不变，选择不陈旧，焦点可见，表单关闭后回到原动作 |
| 导出 | 双图 PNG/PDF、甘特、CSV、JSON | 图像真实、文字可读、两种采样时刻分列、筛选行数与值一致 |
| STOP/退出 | 安全停止、等待排空/保存、真实退出码与子进程回收 | 完整保存，实际退出 0，不仅是窗口隐藏；截图回收/关闭修复无回退 |
| 只读重开 | 同一会话重开、最后截图、历史计划、证据与自检 | 截图摘要和时刻明确，不冒充实时三维；无重新提交或新生产 |

若原生输入问题仍在，按 Qt 容器 → Kit 窗口输入 → Selection 手势层 → USD 拾取 → 对象/工序映射逐层定位，在本地修复并重测。所有失败保留，不以可用替代入口关闭直接鼠标问题。
