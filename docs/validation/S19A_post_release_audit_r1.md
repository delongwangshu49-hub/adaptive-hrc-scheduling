## F1 · P2：导出的USD依赖原工程绝对贴图路径

位置：[地面材质](../../sim/isaac/scene/floor_finish.py#L27)，以及GUI的两处`stage.Export`保存入口（`scripts/view_building_scene.py`第103、257行）。`inputs:file`由当前源文件位置构造绝对路径；导出场景没有复制依赖或将路径锚定到导出层。

复现：从已发布实现建立场景，导出USD；将USD与正确贴图复制到独立审阅目录，重新打开。USD仍引用原工程绝对文件，解析器选择原工程贴图而不是复制到审阅目录的贴图。已核实绝对依赖、目录外解析和原工程仍必需。

影响：单独移动保存的USD到没有原目录的机器/审阅环境时，地面和斑马涂装可能丢失。**当前原工程下贴图存在且能正常解析；完整新checkout重新构建场景的路径会重新计算，此项不声称那种运行失败。**本审阅没有删除或临时挪动真实贴图，也没有冒称在源目录缺失的真实Kit中已渲染失败。

建议修订导出保存入口：随审阅USD携带贴图，并采用相对于导出层的资源路径，或采用包含依赖的USD包；补迁移回放验证。状态OPEN / NOT_FIXED。当前几何、碰撞与调度语义不因该材质依赖问题被判无效。
