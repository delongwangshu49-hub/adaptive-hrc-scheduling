## 决策审计边界

本驱动声明 CURRENT_EVENT_PREFIX_ZERO_DELAY：规划前必须已交付当前完整事件前缀。Isaac 端同时要求事件账连续、前缀和可见状态与已交付账一致；不是对任意丢包或延迟网络作正确性承诺。

审计独立检查事件顺序、配置/运行/epoch、观测版本和时间、状态摘要、事件 ID 摘要、计划观测关联、命令上下文、派工结果及终止观测覆盖。ACCEPTED→STARTED 是一次合法派工；ACCEPTED 本身不能冒充返回的 STARTED 回执。PORT_START 异常须关联该次命令。拒绝过滤只能引用此前已观测的拒绝，不声称独立证明调度最优性。

每端状态摘要包含本端读回来源等身份字段，因此两端摘要字节不强求相等；摘要必须先各自与真实事件前缀吻合，事件、状态、计划及离散字段仍按原容差比较。整数与等值浮点数只做 JSON 数值表示归一化，不对时间或几何差异取整。历史旧格式缺少所需信息时判 INCOMPLETE，不补造观测或将旧 PASS 转记为新因果审计通过。
