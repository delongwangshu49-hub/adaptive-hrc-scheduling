## 5. 分析计划、样本量与结果表达

### 5.1 指标与图表

建议主评价先区分**按期 READY**与**按期外部接收**，冻结二者定义及主次，不根据结果选较好口径；共同窗口内完成数、接收数、未完成数及订单分母同时保留。取消订单、未释放订单与释放后未完成订单分别定义计入规则。

配套指标包括交期/迟期、成品驻留及峰值、OUT1/上游阻塞、缺料/资源等待、运输距离、空载占比、在制品峰值、逐人日历/峰值 F/累计 E/ΣE/max E、生产计算时间与搜索成本。空载占比预先选距离或时间分母并命名，必要时分别报告；零分母标未定义，不填零。不同单位物料不混加；恢复时间、交期及尾部活动明确起止和截尾。

| 拟图表问题 | 输出计划 |
| --- | --- |
| A：同域下交付/成本有何差异，多少运行有效？ | 成对效应及区间、可行/失败统计；少量按预定选例规则选取的甘特图/资源时间线 |
| D：总量改善是否使某人更差？ | 交付—暴露权衡、逐人分布、最重个人及敏感性；不可行点保留 |
| B：信息受损到何程度发生退化？ | 延迟/噪声/缺失曲线或热图；未测试区域与失败率标明 |
| C：何时恢复，成本在哪里，多少未恢复？ | 扰动/恢复时间线、成本分布与未恢复/截尾比例 |

每图固定 ID、问题、数据/脚本入口、版本、配置、配对键、单位、统计单位、分母、样本数与区间算法。示意、合成数据、CPU 仿真和 Kit 读回分开标识；稳定示例选择规则避免挑最好种子。正式图表由后续步骤生成，S20 仅用开发/手算夹具检查流程。

### 5.2 样本量与不确定性拟定方法

以“实例 × 外生情景/重复”作为候选配对单位，明确同实例多种子是否构成簇；决策次数、时间点和事件数不当独立样本。阶段 4 先选主比较、效果尺度及有实际解释的区间半宽/精度目标，再形成每层实例数与重复数、总运行数及资源依据。

建议连续指标以成对差及 95% 区间表达，有实例内相关时按独立实例/簇重采样；成功率与成对成功率差采用适合其样本结构的区间方法。独立单位太少时报告原始点、范围与不可可靠估计说明，不伪造精密区间。方法、重采样次数/种子及多重比较处理在阶段 4 写定，不按显著与否更换。

样本量依据优先用适用的既有开发证据及明确的精度/成本假设；若确需方差估计，仅列入阶段 5 已登记的有限开发小例，并记录其局限。候选样本量须给出精度假设变化下的范围及运行数核算，缺依据时呈交待决，不随意填“30 次”或承诺统计功效。单个开发案例不代表所有实例族。最终样本数和停止规则在正式运行前冻结。

失败率/未完成率以全部预定运行对账；仅对双侧有效配对计算的连续效应必须注明条件分母，并同时呈现失败差异，不能以幸存样本代表全部。到窗口仍未完成/未恢复者记截尾；不把窗口末时刻冒充完成/恢复时刻，也不删掉后当成功均值。任何补充敏感性分析须事前定义或事后明确标为探索性。

## 6. 开发小例验证与停止/补跑

阶段 5 先登记小例清单、固定输入、预期检查、运行上限和输出位置。优先静态解析及既有受测小例，必要的运行仅限以下类别；具体数量在候选设计完成后列明，禁止无限扩成正式矩阵。

1. **结构与身份**：配置可解析；缺来源/缺版本/错摘要/越准入范围/重复或跨 split 身份等负例被明确拒绝；相同配对可再生成。
2. **公平性与观察**：已有同域通道读取同规则、外生流、cap、预算；隐藏未来与诊断真值不进入提案；超时和回退有记录，不给某方法补额。
3. **物流与统计追溯**：复用适用开发小例核验 READY/接收区别、B 与背压、订单/窗口/日历、人因单位和保存事件重建。仅对改动影响点补跑，原 S19B 矩阵不重复执行。
4. **分析管道**：手算夹具覆盖成对差、零分母、单侧失败、缺失、未恢复/截尾及多种子相关；从 manifest 对账到结果/图表，原始记录不可被分析排除悄悄删除。
5. **后端与出口**：需要跨后端证据时，在已适用开发小例上使用真实 Kit，与 CPU 保存记录严格比较并作独立审计；输入、源码、场景及实际退出分别留证。只做解析/追溯所需验证，不开始正式 A/D/B/C。
