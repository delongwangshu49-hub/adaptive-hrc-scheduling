# S20 分析计划候选 r1

2026-10-19；`S20-DESIGN-r1`；PENDING_FREEZE。适用 [协议](protocol.md)与固定 manifest；统计脚本目前只提供开发用有限配对汇总，正式分析器/图表由各后续步骤在获准后实现并验证。

## 问题、统计单位与主次指标

统计单位为一个“产品变体×产品数×外生情景”的方法配对。主集合16个单位、每单位4方法，共64运行。事件、决策、人员、时间点、同一基线被多次引用都不增加独立样本数。四配置是固定设计层，不是从工厂总体随机抽样。

主比较为 ADAPTIVE_JOINT 分别相对 FIXED_H、FIXED_HR、NO_OBSERVATION_UPDATE；同一个pair全信息/规则/预算一致。主指标为**按期外部接收比例**，关键次指标为**按期READY比例**，两者始终并报；不根据效果切换。按期指对应真实时间戳≤产品due_h，未接收/未READY计未达成，合法窗口截尾也不冒充按期。主网格无取消、所有release=0，分母为配置全部产品数；未来扩展取消时须同时保留原释放订单分母和非取消子集，不能删除困难订单。

所有结果先报预定/已尝试/未运行/双审计有效/预算内/截尾/未触发计数。主全设计汇总按16个pair等权；各配置/情景层同时呈现。不是按产品数或事件数隐式加权。各方法审计非法或证据缺失时，实际交付指标为UNKNOWN，不填0；另报“有证据证实按期接收”下界，将未证实项保留为未知部分，并给最大可能值上界，不把此界称置信区间。

| 指标 | 定义、单位、分母与尾部处理 |
| --- | --- |
| 按期/窗口内交付 | READY、外部接收分别计数/配置产品总数；时间h；取实际产品状态/对应事件，名义计划分数不使用 |

## 失败、配对与不确定性

连续效应 `Δ=联合−对照`，单位保持；正负好坏按指标在图例注明。仅双侧证据有效且满足对应指标窗口要求时计算该指标成对差；同时报告全部16对的状态与条件分母，不能只展示幸存收益。预算内分析与全尝试失败表并列；单侧失败不得悄悄删对。

有限主设计的样本量依据是完整覆盖2变体×2数量×4机制的全部16格，每格确定性模型运行一次。没有外生随机抽样、没有外部solver seed，重复相同运行不会增加模型样本。因此**不计算t检验、bootstrap置信区间或p值**。报告每格原值、成对差、平均差、最小/最大、正/零/负数量；这不是用小样本回避不显著，而是匹配实际生成机制。差为0也完整报告。

对这16格的有限均值，只要所有格证据有效就无抽样误差；缺失引入未知范围，数值/实现/模型不确定性仍存在。不能把“无抽样误差”说成真实世界无不确定性。样本精度不外推到随机工厂总体；若负责人要求总体推断，须另定抽样总体、实例生成器、独立情景seed与精度目标，再修改协议，不能事后追加种子追求显著。

R3的8个种子也是预定有限压力集合；按实例×种子保留配对，重复引用确定性基线不当独立观测，主报各配置内种子分布/范围与全部失败。延迟条件无随机输入，重复去重。若升级随机总体推断，按实例簇而非事件重采样，区间/重复数和精度依据须在新版本事前确定。当前无此推断承诺。

资源规模：主64条，C复用主记录；D待批12条；B去除确定性重复后待批544条，另复用16条NORMAL方法基线。总新增正式运行候选620条，但只有64条进入当前主manifest，D/B未实施不伪造可执行行。620不是本轮执行数/获准数/完成数。正式速度或内存统计重复另提协议，本轮不自动运行。

## C 恢复定义

每个挑战以同配置、同方法NORMAL为参照。分别记录首次扰动实际发生 `t0`、恢复条件实际解除 `tr`（到货/接收许可/REPAIR事件）和是否触发；共享触发规则与共享绝对时刻区别标明。

进度恢复候选：在tr之后找到最早t，使共同核心活动完成数不少于NORMAL同一仿真时刻的完成数、无该扰动遗留HOLD/带载故障，且该条件在 `[t,t+8h]` 持续成立；8h稳定窗口及定义待本候选冻结。用两条阶梯轨迹的事件时间并集和区间端点检查，不靠稀疏截图。若t+8>720、参照本身非法/缺证据、挑战未触发或挑战/参照缺失，则分别报右截尾/不可评价/NOT_TRIGGERED/UNKNOWN。恢复时间为t−t0，不能用tr−t0冒充系统恢复。

若两侧都全部接收且不存在遗留状态，在后续8h无新外生事件的冻结情景下，可将“完成数与无故障状态持续”作为吸收状态推导，明确该推导只用于进度恢复，不生成未记录的人因积分。无法证明吸收则维持截尾。材料、退料、清场/重新配送、已发生暴露与尾部成本均保留。

## 分析校验与冻结后变更

开发工具 `paired_summary` 用手算 `(2−1,4−6,8−2)` 核对均值5/3、范围[-2,6]；失败/缺失/截尾不变成0，非法NaN/重复pair拒绝。此函数是最小设计检查工具，不等于上述全部正式指标分析器已实现。正式脚本必须用独立夹具逐指标验证，不能将名义score解析成实际交付。

冻结后布局、窗口、前端负载、生产、观察、统计口径任何实质变化都产生新版本；先登记原因、影响字段/行、重跑范围及负责人决定，旧版本/失败保留。未获最终冻结及后续启动许可时，所有test行保持未运行。
