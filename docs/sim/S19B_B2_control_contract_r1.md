# S19B B2运行与控制契约

2026-10-14，PR181。本地实现已按[B2审阅](../validation/S19B_B2_r2.md)验证；本文件不是负责人验收或发布回执。

运行采用既有NORMAL仿真生产、720h窗口、原在线预算、严格配置准入和观察隔离。默认桌面B2不再自动在1h检查点截尾；旧请求无control字段仍为原前缀模式。未改变生产输入/工时/路线/落点/手位/支承运动、2.4m和0.02h/对。三类剩余支承保持TECHNICAL_OPEN_NOT_FIXED / NON_BLOCKING_FOR_DEMO，工业G2 OPEN/NOT_ESTABLISHED。

## 身份、输入、确认和持久性

每次新运行使用全新目录、run_id、request_id和固定epoch=0。运行中不重置、不恢复后端进程、不增加epoch。桌面明确展示产品、数量、释放时间、备注和后端并要求确认；后端独立校验严格类型/字段、有限数值、数量与时限，核对草稿、后端及三份固定输入文件摘要。构建后的生产配置继续通过原validate。源码清单单独捕获绑定。

控制命令使用S19B-CONTROL-1，包含运行/请求/epoch、命令ID、严格递增sequence、动作、确认以及完整request摘要。启动是序号1；永久exclusive-create worker-claim限制同一目录只启动一次，崩溃后该目录不再启动。不能覆盖已有结果。此为本地文件协议和字节完整性，非多用户权限认证/签名服务。

内容摘要命名的不可变inbox允许重发同一内容。后端单写者以原子JSON先保存受理，再允许驱动产生效果；相同内容返回原确认和当前完成结果，不再执行动作。相同ID不同内容、旧运行/epoch、乱序、未确认、输入摘要不同、非法动作/状态持久拒绝，不消耗成功序号。稳定受理与最终完成分列，超时/传输损坏为未知，不能改成成功或拒绝。

## 状态与停止边界

状态：STARTING→RUNNING→STOPPING→STOPPED或STOP_BLOCKED；正常结束为COMPLETED；异常/审计失败为FAILED。前端已提交、后端已受理、初始化后实际开始、停止处理、最终保存、完整资源关闭和实际进程退出分别显示。心跳超过5秒、身份/来源失配、缺失/损坏记录均未知，禁用控制。

停止在生产循环下一次派工前边界生效。受理后不派发新的生产或服务动作，不引入新的外部生产事件；用原CPU advance / Kit advance_to及USD读回推进当时STARTED动作到原结束点。处理不会取消订单、清除承诺、回滚已发生事实或释放本来仍被持有的资源。完成后创建零命令WAIT决策并独立审计。

所有运行项消失且两审计PASS时为STOPPED；HOLD/无进展/读回异常保留事实并标为STOP_BLOCKED或FAILED，不称成功有序停止。未开始的未来承诺保留于原在线日志，不再派工；未完成订单保持未接收。停止后不提供继续/恢复生产。停止边界的初始命令、事件数、版本、时间及最终剩余命令记录于manifest.orderly_stop。不是工业急停或硬实时保证，长决策/Kit读回期间前端可超时未知。

## 重连与其他能力

重连只读核对原request、控制状态、未决inbox、run_id/request_id/epoch、实际worker PID及内核创建时间；保留内核句柄观察退出，防PID复用。重连不自动重发、创建进程或重新执行历史命令。新前端可选择已有运行目录恢复观察和控制；已退出路径只能核验保存记录与实际退出回执后只读查看。没有退出回执时不得推断exit0。

尚无初始化生产快照时，桌面停止能力不可用，显示未知；不会将关窗或强杀当作停止。实际桌面曾遇初始化前worker线程Suspended，核对身份后恢复该既有bootstrap进程，随后完成同一运行的真实停止/审计/退出；这不开放或验证生产暂停/继续，原未知与诊断记录保留。
