# S19B-5 离线严格比较分组补充协议

2026-10-15，在原程序三试点校准尚未结束、V2及正式11对比较尚未执行时登记。依照已批准r3“全部在线测量完成后最多两个离线任务”的范围，不改变15条运行、11对比较、30项审计或任何比较字段与阈值。

V1三试点实际父进程退出0，采样树峰值806,944,768字节，串行耗时5,206.369秒。原程序校准、V2复用校准和完整结果/负例核验仍先后完成。只有这些核验通过，且已测峰值的两倍不超过4GiB，正式比较才分为两个进程；否则仍串行执行两个分组。该判据不保证真实峰值，执行过程继续实测，异常保留，不强杀。

分组一为两订单三对，以及B+1 A1/B2、B1/B2；分组二为B+1 A1/B1、H1/A1、L/A1及三个短例配对。仍调用未改变的V2入口和原比较器。每个新运行只归一个分组；已有两订单A1/B1、B+1 A1/B1、零预算A1/B1通过校准；实际跨组共享的B+1 A1/B1执行/决策缓存只读复用。启动前验证共享审计及流缓存有效、未缓存流的内容键无跨组写冲突，不允许竞争同一缓存写入。

两个分组各自保留结果、实际退出、耗时、采样资源、完整输入绑定和缓存失效负例。两组自然完成后才按原selection顺序合并，核对11对集合完全相等、没有重复或遗漏、两组输入绑定相等。失败不覆盖原结果，不进行生产重跑。正式比较的实际并行墙钟与累计CPU另列，不将试点缓存复用倍数当作全任务加速保证。随后30项独立因果/候选任务仍最多两个；若比较两组采样峰值之和超过4GiB，后续审计回到单进程。
