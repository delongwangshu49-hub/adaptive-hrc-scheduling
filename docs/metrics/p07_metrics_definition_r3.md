# P07 指标、窗口与来源定义 r3

2026-11-02。本定义用于本次离线统计；运行事实保持原 P043/P053/P051/P063 身份。结果入口为 `results/p07/r3/summary.csv`，逐产品、人员、活动、资源、阶段、机制及计算账在同目录；来源和摘要见 `docs/delivery/p07_source_registry_r3.json`。

| 对象 | 定义、单位与边界 |
| --- | --- |
| 产品/订单 | 由物化后的目录及实际增量确定，订单按 order_id 聚合，产品逐 ID 保留。登记、已释放、非取消已释放分别列数；不按初始目录硬编码分母。 |
| READY / 接收 | 分别使用实际 ready_h / received_h。准时比例以对应实际时刻≤due_h 判断；全释放集合与非取消子集分列。取消不冒称接收；exit=0不代表业务整单完成。 |
| 迟期/下界 | 完成迟期=max(0,实际时刻−due)。未完成者仅给 max(0,观察终点−due) 下界，不补造接收时刻。已取消者保留历史和取消状态。 |
| 新单链 | 请求受理、登记生效、实际到达、首个已交付观察、首次采用计划、首次实际生产STARTED及最终结果分栏。proposal仅为提案，不代替采用。E20计划版本引用由原采用凭证和计划文件摘要绑定。初始产品登记时刻0。 |
| 实际生命周期 | [0,原停止/完成时刻]；动态人员首次到岗前为 NOT_IN_CATALOG。取消STOCK保留原720h WINDOW_CENSORED终态，即使未取消产品已接收。 |
| 共同评价窗 | 固定研究为[0,720h]，原已校验REST尾延拓与实际生命周期分栏；延拓不表示实际生产继续。P043两个局部检查点没有合法720h尾窗，保留 UNKNOWN_INCOMPLETE_LOCAL_CHECKPOINT_NO_TAIL。 |
| F、E | F为无量纲疲劳，E=∫Fdt，单位F·h。逐完整活动区间独立重算线性累积和REST/OFF_SHIFT降至0的截断积分；逐人总E、峰F与保存状态对照；ΣE/maxE均保留全历史人员集合。 |
| 人员分母 | presence按原人员状态区间取并集；availability=presence∩日历∩资格有效期∩可派发人员状态。它表示资格/状态上的可用时间，不等同未占用的空闲工时。返回沿同ID延续F/E/peak，新人不补历史零。逐人活动时长和暴露、离岗记录分别保存。 |
| 劳动费 | presence人时×原run-spec按template_id声明的rate_per_h；PRESENCE_LABOUR-r2、MODEL_UNIT。N/H/U六运行和P043动态用原费率；F/C/纯H直接循环未声明该费率，记UNKNOWN，不跨来源外推。原冻结资源费用策略单列，不能与presence费重复相加或假称完整财务成本。 |
| 占位/在制品 | 复用a_final_results.occupancy：按事件revision保留同刻峰值，按相邻时刻矩形积分，单位product·h；内部完工未接收与开始后未READY的WIP分列。独立事件向量再次对账。 |
| 资源占用 | 相同resource_id/kind区间取并集，避免重叠重复计时。设备所有权、ENTITY锁、物料reservation分层；物料数量预留不是设备占用。代表甘特仅画全部设备，不把物料批次画成机器。 |
| 搬运 | 复用原分段速度加权实际弧长算法，以root/resume链的实际进度去重。总搬运不含WALK；EMPTY_RETURN、载荷/工具、WALK及全路由距离分列；总搬运为0时空返比例UNDEFINED。逐根链和命令连接表可查。 |
| 等待/恢复 | 逐人活动WAIT时长保留；并集核算不重复计重叠。没有唯一原因凭证时不归因单一资源。故障、维修、resume_STARTED/resume_COMPLETED为实际里程碑；resume完成与系统进度追平不同。旧8h追平未冻结参考轨迹和阈值，本次不输出该单值。 |
| 配对 | N/H/F为c1，U/C为c2；只在同情景、同输入约束/来源族、同窗双侧准入后算Δ=ADAPTIVE−EDD。10方法行、5对×9指标=45行。无跨族pooled效应，无p值/置信区间或总体优越性推断。 |
| 四机制 | H/HR×初始F=.2/.60；纯H两次独立运行，HR两格分别引用N/H的EDD。四格不等于四个额外样本。阶段劳动、机器人段、mode_attempts、共同物理输出与全产品结果分开。 |
| 计算账 | 原总墙钟、cycle/decision/search/repair/verification/candidate/fallback等按原字段列出。字段可能嵌套，不能求和为总成本；cycle和原budget.used对账。search_call、候选计时检查次数、实际缓存计划STARTED、回退及超预算分别计数。CPU时间/峰内存未记录为UNKNOWN，不补0。900s预算和累计7次搜索上限仍按原协议。 |
| 双域 | normal/dynamic/kit三组沿原观察信封连接run、epoch、配置、目录、revision、observation及事件前缀；甘特含完整计划，三维是保存的场景域数据，不是新原生渲染或同步截图。Kit旧schema缺order列表，显式与同观察甘特/scene产品状态绑定，不补造字段。 |
| 状态 | PENDING表示未执行的必交动作；UNKNOWN须有记录缺失/未测/定义未冻结等原因。本次固定提取、动态核算、导出、图表、claim及最小再生均已执行；历史性能/业务未达标仍保留原状态。 |

`results/p07/attempts.json`完整保留原四个失败/截尾生产尝试及原辅助失败索引。P07适配、格式检查和图表修订的失败另外登记，不改变历史生产结果。源版本、原实际退出、原独立核验和新离线核验分别登记；离线再生不增加研究样本。

2026-11-02有限修复补充：疲劳曲线按实际分段函数绘制，REST/OFF_SHIFT在区间内部到0时插入零点，每条曲线的梯形面积必须等于相同窗口E。综合门禁对实际数值及表间关系重新核验，错误结果非零退出并记录FAIL。取消后的物料去向按material和quantity_unit分组，逐lot守恒；命令关联人时/暴露及root/resume搬运单列，不摊派未归属等待/休息，没有货币策略不虚构金额。末态清理账不推断精确清理时间。甘特总展示行24680/2676/5241与FULL_PLAN计划行1023/2046/2046分列。旧r2结果、图和审阅失败作为历史保留，当前产物位于r3目录。
