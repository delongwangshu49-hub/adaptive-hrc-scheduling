# S04 研究假设与参数依据

日期：2026-10-01；状态：研究候选，未检验。研究层级保持完整多资源自适应框架之下的 A 核心方法和 D 人因权衡；B 仅作稳健性检查，C 仅作恢复评价。技术路线和范围见 [项目总纲](../../README.md)，来源分级见 [参考文献](references.md)。以下操作化定义用于使假设可审阅，不是 S05 数学规格或 S20 实验协议的冻结。

## 推理与证据边界

R01–R04 表明协作、动态分配和人因优化已有基础；它们不证明本项目能改善交付。R05 的肌肉模型、R06 的重调度框架和 R07 的搜索方法是建模参考，不提供本项目效果的先验保证。完整模式集合包含固定模式解，并不意味着有限预算搜索一定找到更好解；不能把可行域包含关系当成算法实验结果。

每项假设均标为 PROPOSED / UNTESTED。支持或不支持的判据必须在测试数据分析前冻结；本步不预填改善比例、显著性、样本量、最优值或工效安全界限。

## 指标与公平比较的候选口径

- 交付候选主指标是加权拖期；完工时间、可行完成率和计算耗时同时报告。权重、交期生成及取消订单的分母留待冻结。基线指标为零时使用绝对差，不虚构相对改善率。
- 设工人模型状态为 F_i(t)，候选累计暴露 E_i 为在共同观察窗口内对 F_i(t) 的积分；总量为 ΣE_i，个体目标为 max E_i。窗口包含生产、等待和休息，采用一致尾部处理；若另用各自完工窗口，单独报告其变长导致的混杂。峰值上限 F_max 与累计指标不同，D 各方法必须共享该上限。
- F_i 是尚待规格化的无量纲模型状态；E_i 单位随时间基准而定，不是生理测量单位。工人数量不同时，除总量外另报每人均值，不能直接把更少工人的低总量解释为更好保护。最大个体累计值也不能替代每人的峰值检查。
- C 的恢复需要预先定义同一可比性能轨迹、目标容差、持续达标时长和观察窗口。未恢复记为未恢复或右截尾；订单到达/取消后允许目标基准改变，但须事先说明映射，不能用旧产出目标机械衡量新需求。
- 所有对照共享工艺资格、资源容量、疲劳上限、观测权限、冻结范围和回退规则。外生事件序列配对；随机加工时间按稳定任务 ID 和种子管理，避免算法改变调用次序后拿到不同随机世界。
- 开发、调参与测试实例分离。重复次数和统计区间方法将依据试运行方差与成本在 S20 冻结；报告失败、负结果和计算超时。暂停仿真求解的墙钟时间单独报告，不称作部署时限已满足。
- CP-SAT 只在双方任务、模式、时间离散、疲劳近似、资源及目标完全一致的简化模型上比较；R08–R09 只支撑工具语义。须报告状态、解、界与终止设置；时间截断误差和相对间隙的零分母处理另行规定。

这些是项目拟采用的比较规则，不声称每条都来自某一论文。具体阈值、统计方案和模型方程仍需后续审阅。
