# S04 相关工作与项目定位

截至 2026-10-01，本项目已核实：协作排程中的疲劳、状态驱动任务分配、团队与个体人因目标、事件重调度以及 LNS 均有既有研究基础。它们的名称或简单组合不构成首创证据。以下是定向比较；书目、定位和访问限制见 [参考文献与核查记录](references.md)。本项目仍处于研究准备阶段，未获得生产调度或人因实验结果。

## 术语与比较规则

“协作类型”描述人机关系；“执行阶段”描述一次工序内部准备、独立作业、同步、交接和释放的资源占用。两者不混用。H、R、HR 是项目模式标记；HR 是否存在及内部阶段依赖工艺，不能假定所有工序都有三个模式。这里不建立新的协作分类学。

表中“未核实”只表示本轮证据不足，不能解释为论文没有该能力。“项目拟处理”是改造方向或待检验假设，不是已证明的差异。尤其不能从摘要未提到吊机或缓冲区，推导文献完全排除了它们。

## 已有方法、项目改造与研究假设

| 主题 | 已有基础 | 项目拟改造或复用 | 必须由后续证据回答的问题 |

| A：模式与排程 | R01、R03、R04 已涉及协作、分配和人员状态 | 用统一领域模型表示人员、机器人、设备和吊机；分阶段占用，在许可边界调整模式并修复安排 | H-A1：收益排序是否随资源负荷和人员状态改变？H-A2：阶段占用是否改变可执行决策？ |

研究贡献候选是可解释的决策机制及其适用范围，需以合法执行日志、匹配对照、消融和负结果建立。四类资源的组合是本项目范围要求，尚不能称为“无人研究过的组合”。双后端一致性是工程验证责任，也不直接证明学术新颖性。

## 需保留的证据缺口

1. R01、R02 仅获得有限正文信息，不能确定它们与本项目的完整数学差异；在论文式贡献表述前补查原文。
2. 本轮没有取得可用于管道模块各工序的人体测量和加工时间标定数据。所有缺少适配证据的数值应标成合成或待校准，详见 [参数依据台账](hypotheses.md#参数依据台账)。
3. [U01、U02](references.md#日期或访问范围待复核的相近线索) 的题名高度相近且日期待核实；不因排除出当前确证表而忽略潜在重叠。
4. 第一版不覆盖真人试验、感知估计、连续轨迹避碰或精细加工物理。结论将限于所冻结模型和受控仿真；S03 的短时刚体运行证据不扩大为生产闭环或人体安全验证。

本步只整理比较、可检验问题与参数来源条件。具体生产规格、方程、数值、实例和验收规则留待另行授权的 S05 及后续步骤确定。
