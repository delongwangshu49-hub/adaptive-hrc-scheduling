# 完整建筑模块生产：相关工作与研究定位

版本 C03-0.1；2026-10-02；下一版研究定位。既有方法文献R01—R10的已核查范围沿用其真实记录，不冒称本轮全部重读；新增建筑生产核查见[生产证据](production_evidence.md)。现行管道内核不代表建筑域已实现。

## 建筑对象、工艺与方法的证据职责

完整体积模块研究对象有钢与RC两条工程及学术路径；钢连接/子框实验和RC足尺结构研究证明对象成立，不能回答厂内模式时长。BCA的两类生产流程支持结构、MEP、内装与质量链；供应商机器人资料支持局部自动化存在，不能代替工艺资格和整厂收益数据。没有统一检索计量支持钢比RC“学界认可度高”。

Yang与Lu的工厂布局研究只有机构摘要可用，不能抄造其内部工序。Ouda与Haggag的装配模拟不提供本项目完整工厂标定。数字混凝土制造的人因实验对象与传统整体浇筑模块不同；不得为迁入现成参数把候选变成打印构件。

本项目拟将模式和人员状态放进完整产品链、工装/空间驻留、工艺等待、质量与真实搬运的共同约束内。新增工序数量并非贡献；贡献候选是这些条件何时改变合法模式选择、交付和个体负荷，并由控制实验报告失效边界。

## 与已有方法的关系

“顺序协作”和“同步协作”须依工艺定义，不等同所有任务均有H/R/HR。摘要未提某能力不代表文献没有该能力。下表保留S04的有限访问级别（F全文、P片段、O官方文档），与生产证据F/A/E/U分开。

## 新领域需要回答的差异

| 机制 | 本研究拟检验 | 不能据此声称 |
| --- | --- | --- |
| 产品及驻留 | 同一模块贯通不同工种，人员释放后占位仍影响后继 | 只要增加空间约束就必然创新或更好 |
| 工艺等待 | 干燥/养护与人的劳动分开，工装释放由真实门控制 | 等待时间就是人员休息 |
| 模式A | 同输出合格模式在资源竞争和人员状态下收益反转 | 焊接自动化案例已经验证同步HR或本项目收益 |
| 人因D | 共同cap/窗口下总暴露与最大个人暴露比较 | 模型积分下降等于真实健康风险下降 |
| 闭环与恢复 | 实际反馈改变派工；不可见未来事件隔离 | Isaac动画或静态计划即闭环 |
