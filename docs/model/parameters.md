h为建筑文档和契约计量单位。当前适配器向旧数值核心传入时间×60、率÷60，并将返回的F·min÷60还原为F·h；几何/质量不受此转换。所有浮点误差容差只用于复核，不能允许cap、容量或时界违规。参数必须带type/source/unit/validity，缺失资格不允许以E时间替代。

人工二维框H点值展开为装夹0.5+焊接2+卸载0.5h；HR-seq为装夹0.5+机器人1+卸载0.5h。活动表2h是HR候选基础量占位，H必须按模式覆盖为3h。不把整包2h当成全员劳动；观察到OP1监督条件时机器人1h另给OP1监督，不改变机器人时间。

C04/C05实际实现、入口、受测范围与保留HOLD见[建筑执行验证](../validation/building_execution.md)。本文件的研究规格不因代码通过而升级工业资格。
