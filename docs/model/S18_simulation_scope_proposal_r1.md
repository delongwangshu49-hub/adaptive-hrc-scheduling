# S18明确假设下的仿真研究修订方案

2026-10-08；提案 **S18-SIM-SCOPE-20261008-r1**；条款 **SR01—SR08**；状态 **PROPOSED / DECISION_PENDING / NOT_IMPLEMENTED**。PR144仅授权编制本具体方案。本稿与[配套假设表](S18_simulation_scope_proposal_r1.json)共同构成待审内容，尚不改变执行准入、冻结文件或完整S18状态。

## 要作出的决定

建议允许S18在有明确边界的仿真研究中完成生产HR映射、联合调度和两后端验证。完整建筑模块、A模式与排程联合决策、D人因权衡均保留。新的完成标准为“给定已批准工艺假设的完整仿真方法实现与验证”；原来的“先取得本产品工业共同输出资格才允许研究准入”不再作为该仿真范围的必要条件。

这是研究依据及验收标准的实质修订。工业G2仍OPEN，真实接头/WPS/程序/夹具/隔离/检验与停点资料仍未取得，工业执行继续禁用；不得用新研究准入状态覆盖这些事实。旧条件用例、734项检查及S15旧版证据保留原适用范围，不自动算作新版完成。

## SR01：单独的研究准入

拟新增配置用途`SIMULATION_RESEARCH_ONLY`、假设集`S18-SIM-A1`及契约版本`S18-PROD-2.0`。原`S15-PROD-1.0`与C04默认准入不变，新用途不得由旧合成PASS字段自动升级。

新研究门`SIM-ADMISSION`必须同时核对：本方案实际批准记录及假设表摘要；产品/组件/活动适用范围；模式/输出/程序/夹具假设版本；停点/人员规则；完整消费者版本及独立映射检查。全部满足才为`APPROVED_ASSUMPTION_SET`；未批准、缺字段、错版本、越范围、失效或混用旧消费者均拒绝。此状态不命名为“G2 PASS”或“工业合格”。

工业事实使用独立字段`industrial_qualification=NOT_ESTABLISHED`、`industrial_g2=OPEN`；配置、计划、事件、快照、manifest及公开摘要必须保留假设集身份。工业用途输入仍拒绝，不新增硬件控制或现场部署通道。批准仅能提供研究前提，不能产生实际QUALITY/READY/接收事件。

## SR02：Q01—Q06的明确研究假设

| 编号 | 拟批准的模型假设 | 保留的未知与拒绝边界 |
| --- | --- | --- |

| Q03 / A03 | J2固定R1与FIX-J2可完成所列HR阶段；程序/夹具使用假设版本。任一版本变化使旧准备及对应研究准入失效 | 不扩展机器人到J3，不增加机器、工装、可达范围或焊缝路径；焊接本体为符号化定时过程，不做热/冶金模拟 |
| Q04 / A04 | 人工装夹/设定、退出隔离区、机器人加工、停机确认、人工进入卸载依序进行。机器人加工阶段无持续监护职责，OP1可按真实到位/资格规则执行其他任务 | 这是“隔离单元可无人持续监护”的建模假设，非实际安全结论；禁止同步危险区HR。退出/到位/停机状态缺失即HOLD；不加入隐含零成本人员转移 |

| Q06 / A06 | H沿用U1—U6、HR沿用U1—U3作为不可再细分的研究工作单元，单元结束为模型停点。首单元承诺模式及attempt；合法已完单元保持 | 不称为已核定真实焊段。单元中断使该attempt HOLD/待检查，保留已用材料、负荷、驻留和适用资源；不自动重焊或切H恢复。结构返修配方仍未定义 |

人员只在这些模型停点换班，适用时沿用既有双人交接0.1h及检查/恢复0.1h假设与原负荷分类；无合格接替者则等待。机器人阶段后，R1/FIX-J2及对应组件持续持有，直到实际模型卸载成功；晚到、故障或取消不能提前释放。取消仅在已有明确清场规则可覆盖时执行，否则保留HOLD。上述规则适用于新版，旧失败记录不重写。

G1/G4/G5/G6/G7等工业缺口仍按原身份保留。对于已有RP/SC/SH/WV批准的材料、物流、人因及质量机制，拟允许其在新研究用途下沿用相同研究假设与来源绑定；这不改变工业门值。未定义的物理过程不因新用途获得默认许可。

## SR06：共同规则与计算预算

拟实现四个同域通道：联合自适应、固定H、固定HR、完全无观测更新提案。四者使用同产品/物料/运输/人员/日历/保护线/外生情景与共同评价窗口；固定模式同样可调整合法班组、顺序和休息。去更新只根据保留锚点及自身名义推演生成提案，当前反馈仅用于实际安全拒绝、时钟和回执绑定，不参与评分或拒绝后重搜。

开发机制比较同时记录每次与全程累计的搜索调用、迭代、修复试次、验证耗时和墙钟上限。拟采用共同调度时隙/同一运行累计搜索额度的配对口径，额度在运行前写入manifest；提前停止或未用额度均披露，不通过事后多给联合方法预算求收益。具体预算数值仅作S18开发验证配置，必须先记录再执行；S19性能/回退与S20正式协议不在此处启动。

原一次冻结搜索与多次自适应搜索结果继续标为机制证据，不能重标为同总预算效应。无益、反向、拒绝、INVALID及截尾全部保留；窗口未完成不借用名义分数。双后端对照使用同一输入版本、捕获源码及外生事件，隐藏未来不能进入提案。

## SR08：总纲替换文字及批准后的动作

拟在总纲S18及相应步骤卡采用以下前置与失败出口，旧文字保留历史版本：

> S18在已批准、可追溯的仿真假设集适用范围内开展状态依赖H/HR-seq与排程联合决策。研究准入核对假设集、版本、共同输出定义和全部约束；工业共同输出资格保持单独核验。工业G2 OPEN不阻断获批仿真范围的实现与机制验证，但继续阻断工业执行与工业资格主张。未获批、越范围或模型定义缺失的输入拒绝。

> 只有新版生产联合方法、共同域对照、V01—V08及完整双后端链取得实际证据，才可交付“S18仿真范围实现完成、工业资格未建立”的候选。程序验证、人工验收、确切发布分别记录。正式A/D效果结论仍在后续获授权并冻结协议后形成。

这是替换完成口径，不是宣布满足原工业前置。未来S20—S25相应区分“假设下的方法效应”与“实测工业推广”；本稿只认可这一规划承接，不启动后续步骤、不删A/D责任。

建议一次批准SR01—SR08及配套假设表，并授权直接完成本范围内契约、执行、独立审计、算法、Kit验证、必要缺陷修复与收尾，不在每个内部子阶段重复请求启动许可。实施顺序为准入/Schema→轻量阶段与审计→生产联合/对照→Isaac读回→完整链/回归→确切成果包；前一出口通过后继续下一项。超出本表的数值/设备/几何/工艺扩展先形成具体修订，不自行改变。
