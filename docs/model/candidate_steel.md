## 产品和完成边界

S-room 为带指定湿区的居住单元模块，钢框架、水泥板楼板基底、轻质隔墙与围护、机电和墙地顶内装，厂内保护并放行至出厂位。Nanyang Crescent 的钢框架/水泥板楼板案例证明该构造组合存在（F，B01 p83）；本研究湿区组合、精确尺寸、板厚、节点及防火构造为 A/U，不能声称复制该项目某房型。

BOM：切割钢材及连接件 → 底/顶/侧二维框与立柱 → 三维结构；水泥板及楼板支承；轻钢龙骨、保温/防火板及面板；给排水和电气套件；防水、铺贴、涂装材料；门窗/外覆层；吊顶、卫生洁具、柜体；保护包装和身份标识。外购件在进入工作包前齐套检查，构件ID归入同一 product_id。数量按C03图样冻结，不杜撰工程BOM。

水泥板楼板减少结构混凝土养护这一条依赖，却不消除湿区防水、胶粘和涂装等待。内部 ceiling 是产品内装；结构顶框与运输防雨覆盖另列，不将遮雨布当永久结构屋面。

## 可选模式及人因

S1 的候选输出为同一批已满足图样与质量门的二维框。H 由合格焊工完成；HR-seq 为人工装夹/设定 → 隔离区机器人焊接 → 人工卸载/检查的顺序分工。B01 p48 直接支持适用焊缝可由定制机器人替代人工；B02 提供模块框架自动化工程案例。**这支持候选路线，不证明本房型所有焊缝已获双模式工艺资格。** 人工装夹子阶段、边界及人员释放是A，需核对工艺文件；R是该包中的加工阶段，不把全包称无人作业。同步HR暂不纳入。

可达性、夹具、焊接程序/接头资格或质量标准不匹配时删除机器人选项，不能用加大速度收益保留非法模式。共同输出检查适用于H和HR；不设置疲劳导致缺陷概率，也不假定机器人缺陷率为零。S2初版只给人工班组，避免把整模块所有焊接都推给单机器人。

D按具名人员活动核算；机器人运行时只有明确解除职责并安排的休息才算恢复。连续焊接可停点应按焊缝/工艺确定，不能每个数值步自动休息。后续长任务需班次、交班与进度保存；手算不验证完整疲劳执行器。
