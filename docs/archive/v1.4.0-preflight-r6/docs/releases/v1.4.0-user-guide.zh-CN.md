# HRC Workbench v1.4.0 本地候选使用指南

应用 1.4.0，核心库 0.1.0，基于 v1.3.0 native-r2。当前为本地开发候选，原生操作验收与最终封包尚未完成，暂不发布。三维直接点击、框选和退出行为须由本轮实际操作确认，不能用离屏界面或程序化选择代替。

## 启动与自检

完整解压便携包，保留 HRC-Workbench.exe 同级的 app 目录。首页选择“启动完整仿真”，核对产品模板、初始件数和执行方式；高级参数可调整方法和模拟倍率。Isaac 为默认执行方式，需要本机 Isaac Sim 6.1、PowerShell 7 和纯 ASCII 可写结果路径。选择“检查并启动”后，启动条件通过才创建会话。

CPU 数据模式、数据示例与历史会话是显式入口。它们不代表实时 Isaac 场景。首页场景图是此前实际运行的静态预览，与新建会话当前状态无关。

“设置与帮助 → 运行自检”先列需要处理的项目，通过项折叠。快速检查核对启动条件；完整检查补充文件摘要、依赖和日志。按报告中的确切路径修复，保留原错误与日志；界面打不开时运行同包 HRC-SelfCheck.cmd。诊断报告可能含本机路径，分享前可检查。

## 双图与选择

Isaac 在左，甘特在右。双图运行、场景讲解与排程分析改变比例，两图始终保留；窗口至少需要 1280×720 客户区。表单、变更记录、自检和指南在底部独立区域展开，面板内部可滚动。

界面采用中性灰黑底色。灰蓝细框表示选择，灰绿色实心条表示实际执行，浅灰空心条表示计划。选择工作会同步其关联三维对象；物理构件通过已登记的工序关系联动，不按名称猜测。多选保留全部关联对象，空白或无关联选择清除旧工序提示。选择本身不移动相机；“聚焦对象”与“上一视角”负责观察位置。尚未进入场景的产品不能聚焦。

三维点击、拖动框选、Shift/Ctrl 组合选择的最终可用范围以本轮原生验收记录为准。当前候选已补齐选择映射、清空、多选及输入分层诊断；尚未宣告鼠标操作通过。

## 甘特与工单

“当前生产”显示模拟时刻附近的区间并滚动到相关工序；“全程”查看完整计划；“所选对象”查看相关工作。搜索用于查找工序。筛选、资源视图、产品概览、旧新对比、名称栏宽和导出收在“视图与导出”。鼠标滚轮纵向浏览、Shift 滚轮横移、Ctrl 滚轮缩放。极短工序的点击范围可以放大，其实际数值与绘制端点仍保留。

普通单与急单在命令栏直接进入；人员到离岗、缺勤/返回在“人员变更”；交期/优先级、设备故障/维修及取消在“工单与设备”。核对业务参数后确认提交，技术身份可展开查看。提交后保留原请求的回执，查询不会新建请求。手动休息仍未实现，入口明确禁用。

ACCEPTED 表示持久接纳，APPLIED 表示业务变更生效；两者都不表示产品开工或完工。急单重排期间保留旧的已验证计划，显示等待及核验状态。不要因等待而重复提交。新计划通过执行与因果独立核验、实际前缀与冻结前缀检查后才采用；新工单进入生产后，场景才出现相应实际变化。

本版恢复原生计时封装下的安全复用，并对单次回放的几何准备做有限缓存；没有缩短仿真范围、减少约束或取消核验。固定输入性能对照与原生端到端成绩分别报告，当前不保证 60 秒或 50% 提速。

## 导出、停止与重开

“视图与导出”提供双图或甘特 PNG/PDF、筛选 CSV 及完整 JSON。双图导出需要活动 Isaac，会分别标注场景与数据采样时刻；不能把两次采样当作严格同一帧。

结束时用“安全停止”，等待安全段排空、完整保存和实际进程退出。窗口消失不代表保存或退出成功。已结束会话有经摘要校验的最后截图时显示静态画面及采样时刻；缺少旧版截图元数据时明确提示无可验证截图。只读重开不启动 Isaac，也不是三维回放。

原 v1.3.0 的截图收尾与实际退出修复保留，本轮仍须复验。E12 负责人本人验收、组员电脑复测、原研究性能和工业资格限制保持；具体完成范围见本地验收记录。
