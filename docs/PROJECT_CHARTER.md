## 对象与研究问题

厂内生产从材料/组件齐套、二维框与三维结构，到楼板/围护、机电/湿区、墙地顶和内装、质量放行、保护及出厂就绪。产品连续身份跨越全部阶段，空壳或管道子组件不算交付。SR-W1/W2的任务级BOM、变体及质量门见[专属规格](model/selected_steel.md)。场外运输和现场安装只作边界，不声称优化全生命周期或真实工厂数字孪生已标定。

整体成果为完整多资源自适应调度框架；A为状态依赖模式与排程联合决策，D为共同个体保护线上交付与人因的权衡，B仅反馈稳健性，C仅恢复评价。核心问题是人员状态、工装/设备、空间驻留和质量/等待如何改变同输出合法模式收益，以及收益何时消失或反转。全局交付、总累计暴露与最重个人暴露须同时可检查，不以局部加工提速替代系统结果。

H/HR-seq候选只用于符合共同输出资格的底/顶框工作包；R为其中的隔离加工阶段，同步危险区HR不纳入。G2未取得本产品同接头双模式资格，默认禁用HR，A实验不能开始。不能通过调整时间/负荷或负责人认可文档来制造工业资格。若证据无法补齐，需另行裁定研究范围，不能偷偷降为纯人工排程。

### 研究边界与分层

扩展生产边界拟从“已齐套的KIT入口”前移至“合成到货批次进入厂内收料位”，贯通待检/放行、分类储存、必要预处理、齐套配送、结构制造、MEP/内装、质量等待/返修、包装与READY。外部采购、供应商生产、道路运输及厂外配送仍作为外生边界，不扩成供应链优化。READY仍是符合既定质量和出厂准备条件的状态；OUT1外观不能替代质量放行。

区分产品/组件重载流、原料及配套件供给流、人员与工具流。只有影响开工、资源占用、时间、空间、质量或人因的过程进入活动/状态；不逐个紧固件扩张模型。切割之外的预处理项目先核对选定钢体系和实际接口证据，不能把一般工厂常见设备全部列为本项目必需。涉及新增工艺与设备资格继续标记来源、假设及缺口。

S13可移动坐标、展示料架和检查路径，但不新增生产资源容量。布局采用版本化固定配置；先比较有限候选及敏感性，不把在线排程扩展为同时优化建筑平面或连续运动轨迹。A联合模式/排程与D人因仍是研究主体，B和C保持既定辅助范围。

### S14 前置契约修订出口

这一出口安排在S13修订验收后、S14适配代码实施前，作为S14的前置工作包，不新增或重排S步骤编号。启动时须先呈交涉及D01—D06的逐条变更表，取得对应范围的明确修订授权；本补丁或S13方案获批不自动解冻。若未获授权或证据不足，应明确阻断扩展全流程，不退回旧KIT入口却仍宣称扩展已完成。

拟形成 `docs/model/material_logistics_extension.md` 和 `docs/validation/material_logistics_contracts.md`，其中包含旧新契约映射、工序/物料流图、角色责任、时间及负荷假设、Schema版本、迁移/回归清单和验收例。以下是必需决策项，具体字段名与数据结构在授权后的契约设计中确定：

| 契约项 | 拟新增或细化的含义 | 必须解决的问题 |
| --- | --- | --- |
| 材料批次与库位 | 数量/单位、来源批次、位置、待检/放行、可用/预留/在途/已用/退回/报废 | 不同产品不能重复预留同一数量；位置唯一；库位容量与产品bay容量分开 |
| 预处理与齐套 | 原料到输出批次的关系、加工/设置/交接活动、供给某产品或工序 | 原料与预处理成品不双重可用；KIT不再是凭空物料来源；数量换算有依据 |
| 运输任务与设备状态 | 源/目标、载荷、设备、操作者、挂接/装卸、空载行程、占用与目标接收条件 | 无目标容量不得凭空卸货；拒绝/取消不丢料；故障时位置/所有者可追溯 |
| 人员与工具到位 | 起终位置、资格、走行/准备时间、工作/等待/休息类别、设备转场 | 人员不能瞬移或同时到两工位；WELD1等共享设备不能复制；行走不自动算休息 |
| 路径与区域 | 布局版本、有限路径段/交叉口、预约范围、驻留和工作面 | 料架/子器具不增加既有令牌；冲突与释放边界明确，通行检查不冒充工业安全认证 |
| 观察与事件 | 实际发生时间、观察到达时间、来源与关联ID、隐藏未来到货信息 | 同可见历史派工一致，不能由规划器写入实际成功 |

守恒至少分别检查同单位材料的期初+到货=期末在库+在途+已投入+退回厂外+报废；内部退料只改位置/可用状态，不作为额外到货。预处理转换须用显式输入输出映射和余料/损耗记录，各材料类别不能无依据相加。取消、部分加工与返工保持谱系和已经发生的消耗，不能把消费量全数恢复为可用。

契约修订的代码责任范围须事先列出：规格、领域模型、Schemas、实例生成器、轻量执行器、S10独立检查器/指标、S11可行生成器、S12观测与重排，以及未来Isaac生产/消费端。不能只给Isaac端增加状态。旧37项链保留为带版本的回归基准；新链允许因获批细分增加活动数，但不得让拆分前后累计时间、负荷、资源占用和材料消耗静默变化。

出口：最小收料—预处理—配送—开工纵向用例在轻量端可执行，独立检查通过；重复预留、超库容、未放行用料、错批次、缺角色、不可达、取消丢料、未知未来泄漏均有预期失败例。契约及迁移确认后再进入S14适配主体；失败回到具体规则/接口修复，不通过跳过检查推进。

### S14 生产物流与实际反馈承接

在原命令确认/拒绝/延后/开始/完成/异常状态机上，增加已批准的库存、预处理、配送、人员到位和设备准备状态。场景实际观测应能拒绝未到位人员、未放行/未送达材料、占满交接点和被占路径；卸货成功后再释放载荷与运输持有，不以预定终点代替读回。字段覆盖不足时先修复共用契约，不旁建仅Isaac理解的私有状态。

拟扩充 `docs/sim/adapter.md`，增加命令—场景对象—实际读回—事件对照表；记录S13 `SCN-`预留对象中哪些被正式提升为域对象、哪些继续仅供显示。交接顺序含工作面准备、角色到位、挂接/退出、运动、落位和释放；共享人员与设备的所有权须贯穿转场和等待。普通生产机器自动循环不自动成为机器人协作。

出口须含真实场景的到货未放行、工位缺料、目标位满、人员尚未到位、路径阻塞、同设备双请求、WELD1转场、故障后带载停留/恢复及重复/迟到事件用例。执行日志逐条通过S10扩展独立检查，拒绝不产生材料消耗或假完成；合成脚本与单元接口测试不能代替真实反馈。交给S15的是可产生生产事实的两后端共用接口及实际差异清单。

### S15 收料至出厂与两产品闭环出口

既有KIT至READY保留为回归；新增同版布局、材料、角色、规则和时间假设下的收料至READY完整链。关键检验/包装仍按具体工序所在位置执行，Q1保持异常隔离用途，不把其改成正常链统一终检站。未完成、失败和返修分别记录，不能靠夹具跳转消除过程。

新增至少四类成对见证：单产品正常全链；两个产品争用吊机/人员/有限缓冲；缺料或到货延迟导致后续派工变化；实际路线/目标占位或设备异常引发等待与恢复。取消/退料和质量返修另有守恒用例。包含空载回程、装卸、人员走行和准备时间，不把这些时间只算在Isaac端。

交付扩展 `scripts/compare_backends.py`、对照manifest和 `docs/validation/backend_parity.md`。逐产品/批次/活动/尝试对齐位置、数量、锁、工作面、时钟和人员日历；离散不变量一致，连续时间/运动差异按事前确定的误差界解释。必须有Isaac产生的变化反馈影响下一派工，不能重放预制排程；几何到达和生产质量放行分别验收。
