# 模型与版本承接摘要

当前模型映射身份P02-MODEL-r2，运行源码来源step-S20-r4。完整钢模块模型有37工艺节点/40前序边，SR-W1单件含448条全分支静态工序，正常历史有效分支完成436条；15名人员、10个设备（含机器人/机器/龙门吊/车辆/工装），位置/物料及动态服务另计，不能以设备数代替全部资源。

人工与人机顺序协作在适用任务输出一致；HR阶段明确人员准备/退出、机器人加工、停机/卸载的占用。工作、等待、休息和班外按已有参数积分疲劳F和累计E，REST/OFF_SHIFT按恢复方程，E连续不重置。现有受限手工交接为共同交接0.1h+新人员RESTORE 0.1h，核完整资格/日历/F及持有；不扩大为任意吊载/机器人安全替班能力。原15人参数及18阶段表已在受控P02清单保存，生产规格见[模型规范](../model/specification.md)。

P02修订补充阶段/人员全部关键字段核对与拒绝反例、核验标签定位及空班组工时公式约定。模型/参数/原实验数值未为设计文稿更改。动态新增人员继续引用受支持参数模板，返回同ID保留全部历史；新人过去显示NOT_IN_CATALOG而非补零。

P01资产按用途承接完整/局部/失败证据，配对比较须共同核心语义或明确影响证明；不要求全部历史重跑成同一版本。最终新五情景两方法及高疲劳四机制尚未全部核验；本摘要不作整体T需求完成公告。
