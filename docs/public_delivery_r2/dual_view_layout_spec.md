# 同权三维与实时甘特布局设计 r2

2026-10-22；`P03.3-DESIGN-r2 / DESIGN_ONLY`。本文件为P05实现、P06核验及P08操作的设计输入；本轮没有运行Qt、Kit或前端原型。字段来源见[时间线规范](timeline_source_spec.md)，连续操作见[案例协议](interaction_case_protocol.md)，容量见[估计](capacity_estimate.md)。

## 默认布局与面积口径

主窗口客户区使用逻辑像素。顶部运行条64高，底部状态条32高，左右及图间边距各8；运行条保留状态/时间、连接/数据年龄、常用变更、关闭接单和停止入口。按客户区宽度W≥1440使用左右图，W<1440使用上下图；1280×720及1366×768因此用上下图，1920×1080用左右图。这是确定性断点设计，后续可据测量另立修订。

每个图自己的32高标题、40高工具栏、甘特标签轴/时间轴、3D导航覆盖、滚动条均不算绘图区；面积为实际未被遮挡的canvas矩形宽×高。先量甘特标签轴（初始160宽）/时间轴（24高），再给3D侧保留等量留白，以两个canvas的可用空间二等分；不能仅按外框宽度声称同权。默认及“恢复等分”后 A3D/(A3D+AGantt) 与 AGantt/(A3D+AGantt) 均在[.45,.55]。辅助日志默认收起，选中详情显示在图下可收起区域，不覆盖canvas；打开后重新平分剩余绘图区。导出中记录客户区、两canvas矩形、DPR、字体缩放、辅助面板状态及面积比。

```text
宽屏：运行身份/模式/时刻/两图年龄 | 新订单 人员 故障/维修 休息 关闭接单 停止
      [三维 标题/对称放大]       | [实时甘特 标题/对称放大]
      [导航/筛选]              | [工序/资源 旧新对比 缩放 导出]
      [3D canvas 50%]         : [Gantt canvas 50%]
      [可收起选中详情；请求回执抽屉；辅助日志]
      [提交/受理/等待/生效/业务结果、保存、未知状态]
窄屏：同一运行条（按钮可流式两行，总高度实测后重算）
      [三维 标题/工具栏/canvas]
      --------可拖分隔--------
      [甘特 标题/工具栏/canvas]
      [详情/状态；辅助日志默认收起]
```

绘图区默认最小候选尺寸为上下各宽≥960、高≥160，左右各宽≥640、高≥640；小于候选时仍保留两图和输入，压缩辅助区、收起详情、流式工具栏及局部滚动，不把其中一图移到互斥标签。若真实客户区低于1280×720，显示“低于受测客户区”及可达的恢复布局，仍不得静默隐藏图；该范围不预先承诺可用。

分隔条可拖至30:70–70:30，用户调整后明确标“自定比例”，不作为默认等分通过。两图各有相同尺寸/快捷键逻辑的放大与恢复控件；放大是用户主动的临时检查状态，隐藏另一图须有醒目的“恢复双图”入口。退出放大恢复上次自定比例，“恢复等分”清掉自定比例。切换宽窄方向保持选择、时间窗和筛选，以等分重置面积。最大化、DPI迁移及语言切换重算canvas，不重启生产。

## 输入与操作流程

运行前：场景/方法/后端/profile→初始订单和人员→双端校验→规格预览→确认启动。预览显示RunSpec摘要及能力注册表版本，启动后用worker实际摘要确认；拒绝保留字段定位。旧工作台的start/stop能力不能代替新表单消费者。

运行中：运行条入口→非模态可停靠表单→展示当前版本和输入合法性→提交→持久回执逐阶段显示。表单停靠时图继续等分剩余可用区，不能盖住其中一图；窄窗表单为可收起底部区域，摘要/提交/关闭持续可达，表单内部可滚动。普通/急单用同一个新单表单；人员分到岗、返回、计划离岗、突发缺勤和休息，不能用相同按钮的隐式副作用替代。

提交后的SUBMITTED/UNKNOWN与服务端ACCEPTED/WAITING_BOUNDARY/APPLIED/REJECTED分列，实际到岗/离岗/完成接收另列。接纳前拒绝不带accept_sequence，不能显示null或伪造序号。关闭接单显示fence及待排空数，停止显示残余/截尾而非“完成”。输入对话框与Kit更新/调度分线程，显示事件不能写生产状态。

选择一个工序/产品/资源→两图按稳定ID定位；无实体或尚未到岗时定位到详情“未实例化/未在目录”，不生成虚假对象。筛选只改变视图，选中隐藏对象时显示恢复筛选入口。甘特缩放/拖动和3D相机独立；“跟随当前”与“定位选中”显式切换，不因鼠标滚轮提交生产事件。键盘焦点顺序为运行条→3D→甘特→请求/详情，控件带可访问名称，颜色同时配线型/文字；中英切换不丢请求草稿/幂等ID。

## 窗口与缩放核验矩阵

1280×720、1366×768、1920×1080各与100%、125%、150%组合，共9条件。每条件先记录物理工作区和DPR，再请求对应逻辑客户区；物理屏幕不足以容纳的条件记UNAVAILABLE，另在获准测试机测，不用超屏截图冒充可操作。逻辑尺寸不能再乘缩放后当作另一条测试。每个可用条件检查默认/日志展开/表单输入/中英长标签/拖分隔/两图分别放大/恢复等分/跨屏DPI迁移（可用时）；截图和矩形测量同采样并保留遮挡掩码。

检查关键字段和提交/关闭/恢复/停止按钮可达、焦点无陷阱、两图文字可辨；默认及恢复面积比通过；图内可滚动但不能靠主窗口整体横向滚动找常用输入。P06保存每条件PASS/FAIL/UNAVAILABLE及原因，P08由负责人实际操作另签；静态算术核验不等于GUI通过。

实际屏幕/DPI及九条件可用性尚未核验；后续保存实际条件/矩形/结果。本轮未运行GUI或改变显示设置。

本r2仅衔接P03.3有限修复后的当前导航；原布局/容量/日期估计范围和原r1保持，未新增GUI或性能测量。
