## Run and reproduce

Extract the complete proposed Windows ZIP and start HRC-Workbench.exe beside app. Python 3.12.13, Qt, OR-Tools and the frontend are included. Start one SR-W1 CPU product from Launch configuration. During a change, keep the previous verified plan visible until the new version is independently checked. Use Safe stop and wait for durable acceptance, saved completion and actual worker exit. Open saved sessions read-only.

For optional native 3D, configure separately installed Isaac Sim 6.1 and PowerShell 7 and an ASCII-only results directory. The tested path is a local synthetic USD simulation with a private session. It does not connect physical equipment or external business systems. Other machines and versions remain unqualified.

From the source root, use the locked environment and `python scripts/check.py` with Python 3.12.13; this runs source checks, builds distributions, creates a separate wheel environment and repeats the complete test suite. The frontend uses its existing lock: `npm ci`, `npm test`, `npm run build` in desktop/p051/web. The report rebuild instructions are in [reports/w5/BUILD.md](../../reports/w5/BUILD.md).

Before launch, set `P051_PREVIEW_REUSE=0` to select original full-copy, original geometry and unseeded Python preparation. `P051_WAIT_FEEDBACK=0` hides added waiting feedback. Verification, write protection and STOP remain active. Restore the default by removing the environment variable and starting a new session.
