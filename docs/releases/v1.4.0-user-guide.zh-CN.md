# HRC Workbench v1.4.0 本地候选使用指南

应用 1.4.0，核心库 0.1.0。已完成本机三维点击/框选、工单和资源联动、双图导出、安全停止、保存及实际退出验收，最终存档已只读重开核验。本地候选尚未发布。完整结果与覆盖范围见[原生验收记录](../validation/UX_v1.4.0_native_validation_r1.md)。

## 启动与自检

完整解压便携包，保留 HRC-Workbench.exe 同级的 app 目录。首页选择“启动完整仿真”，核对产品模板、初始件数和执行方式；高级参数可调整模拟倍率。Isaac 为默认执行方式，需要本机 Isaac Sim 6.1、PowerShell 7 和纯 ASCII 可写结果路径。选择“检查并启动”后，启动条件通过才创建会话。

CPU 数据模式、数据示例与历史会话是显式入口。它们不代表实时 Isaac 场景。首页场景图是此前实际运行的静态预览，与新建会话当前状态无关。

“设置与帮助 → 运行自检”先列需要处理的项目，通过项折叠。快速检查核对启动条件；完整检查补充文件摘要、依赖和日志。按报告中的确切路径修复，保留原错误与日志；界面打不开时运行同包 HRC-SelfCheck.cmd。诊断报告可能含本机路径，分享前可检查。

## 双图与选择

Isaac 在左，甘特在右。双图运行、场景讲解与排程分析改变比例，两图始终保留；窗口至少需要 1280×720 客户区。表单和变更记录在底部展开；自检与指南在工作台侧边展开，面板内部可滚动。

界面采用中性灰黑底色。灰蓝细框表示选择，灰绿色实心条表示实际执行，浅灰空心条表示计划。选择工作会同步其关联三维对象；物理构件通过已登记的工序关系联动，不按名称猜测。多选保留全部关联对象，空白或无关联选择清除旧工序提示。选择本身不移动相机；“聚焦对象”与“上一视角”负责观察位置。尚未进入场景的产品不能聚焦。

本机已实际验证设备、人员与物料点击、多对象拖框、反向拖框和空白清除。Shift/Ctrl/Alt 与鼠标组合的事件映射有程序检查，但本轮自动操作接口不能持续按住修饰键，因此该组合未记为实际鼠标验收通过；多屏和其他电脑也待分别验证。

## 甘特与工单

“当前生产”显示模拟时刻附近的区间并滚动到相关工序；“全程”查看完整计划；“所选对象”查看相关工作。搜索用于查找工序。切换浏览层级或筛选时，列表回到顶部，避免旧滚动位置藏住结果。筛选、资源视图、产品概览、旧新对比、名称栏宽和导出收在“视图与导出”。鼠标滚轮纵向浏览、Shift 滚轮横移、Ctrl 滚轮缩放。极短工序的点击范围可以放大，其实际数值与绘制端点仍保留。

普通单与急单在命令栏直接进入；人员到离岗、缺勤/返回在“人员变更”；交期/优先级、设备故障/维修及取消在“工单与设备”。核对业务参数后确认提交，技术身份可展开查看。提交后保留原请求的回执，查询不会新建请求。同 ID 返回会显示该人员最后核验的位置，不能用其他人的位置替代；位置未知时先等待新数据。手动休息仍未实现，入口明确禁用。

ACCEPTED 表示持久接纳，APPLIED 表示业务变更生效；两者都不表示产品开工或完工。急单重排期间保留旧的已验证计划，显示等待及核验状态。不要因等待而重复提交。新计划通过执行与因果独立核验、实际前缀与冻结前缀检查后才采用；新工单进入生产后，场景才出现相应实际变化。

本版恢复原生计时封装下的安全复用，并对单次回放的几何准备做有限缓存；没有缩短仿真范围、减少约束或取消核验。固定输入性能对照与原生端到端成绩分别报告，当前不保证 60 秒或 50% 提速。

## 导出、停止与重开

“视图与导出”提供双图或甘特 PNG/PDF、筛选 CSV 及完整 JSON。双图导出需要活动 Isaac，会分别标注场景与数据采样时刻；不能把两次采样当作严格同一帧。

结束时用“安全停止”，等待安全段排空、完整保存和实际进程退出。窗口消失不代表保存或退出成功。已结束会话有经摘要校验的最后截图时显示静态画面及采样时刻；缺少旧版截图元数据时明确提示无可验证截图。只读重开不启动 Isaac，也不是三维回放。

本轮保留并复验 v1.3.0 的截图收尾与退出修复：最终 Isaac 和工作台均实际退出 0；最终存档重开后 79 个文件摘要保持。E12 负责人本人验收、组员电脑复测、原研究性能和工业资格限制保持。急单登记与计划核验已通过，本次停止前尚未推进到新增产品的实际开工，不把计划条当作实物执行证据。
