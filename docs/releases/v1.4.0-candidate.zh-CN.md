# HRC Workbench 1.4.0 候选版本说明

Isaac 全仿真与甘特图继续共同组成生产工作台。工单、人员和设备的变更通过同一业务会话进入排程与物理执行；请求接纳、变更生效、计划核验和实际执行分别显示。

本版本为本地发布候选，尚未提交、推送或上传。应用版本为 1.4.0，核心 Python 库版本保持 0.1.0。

## 使用变化

- 修复嵌入 Isaac 窗口的点击与拖框输入，支持关联工作、多对象选择和空白清除；切回工作台后可继续输入。
- 恢复中性灰黑底色，控件圆角统一为 3 px，统一焦点与选择样式。双图比例可调整，表单与回执在独立区域展开。
- 修改工单时回填现有交期与优先级；人员返回时自动显示已核验的原位置。确认页直接显示目标 ID。
- 修复极小时间舍入差导致的多余重排与冻结前缀误拒绝，保留实际事件、角色与工序的严格核验。
- 双图导出按场景实际尺寸分配空间；导出提示避开底部确认区域。
- 安全停止分别显示持久接纳、排空、保存和实际退出；只读会话显示经核对的末帧与计划。

## 性能与适用范围

同机固定输入的预检对照中，总墙钟中位数从 273.498 s 降至 230.917 s，降低 15.57%；一对运行反而慢约 37.2%。该对照绑定预检代码，早于后续时间边界修复，不能当作最终原生程序的普遍速度保证。60 s 和提速 50% 的拟定目标仍未达到。

实际原生操作、完整回归、退出及剩余覆盖见[验收记录](../validation/UX_v1.4.0_native_validation_r1.md)。负责人 E12、其他组员电脑和多屏环境仍需分别验收；手动 REST、在制品取消及原研究和工业资格限制保持。
