# HRC Workbench 1.4.0 candidate release notes

The workbench keeps full Isaac simulation and the Gantt chart together. Orders, people and equipment share one business session across scheduling and physical execution. Request acceptance, application, plan verification and actual work are shown separately.

This is a local release candidate. No commit, push or upload has been performed. The application version is 1.4.0; the Python core library remains 0.1.0.

## Changes

- Repair clicking and rectangle selection in the embedded Isaac window, with linked work, multiple entities and empty-space clearing. Workbench text inputs regain focus after scene interaction.
- Restore neutral charcoal surfaces and consistent 3 px control corners. Adjustable dual views retain both panels, with forms and receipts in a separate area.
- Populate order edits from the current due date and priority. Same-ID personnel return displays the verified previous location. Confirmation shows the target ID directly.
- Prevent tiny time-rounding differences from causing redundant replanning or false frozen-prefix rejection. Actual events, roles and operations retain strict verification.
- Size dual-view exports to the actual scene image and keep export feedback clear of confirmation controls.
- Show safe-stop acceptance, draining, saving and observed process exit separately. Read-only sessions display the verified final image and plan.

## Performance and scope

In the same-machine, fixed-input preflight comparison, median total wall time decreased from 273.498 s to 230.917 s, or 15.57%. One pair was about 37.2% slower. This comparison is bound to the preflight code, before the later time-boundary repairs; it is not a universal performance guarantee for the final native program. The proposed 60 s and 50% improvement targets remain unmet.

See the [validation record](../validation/UX_v1.4.0_native_validation_r1.md) for actual native actions, full regression, exit checks and remaining coverage. Owner E12, teammate computers and multiple displays require separate acceptance. Manual REST, work-in-progress cancellation and the existing research and industrial qualification limits remain.
