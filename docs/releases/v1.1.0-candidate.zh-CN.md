**v1.1.0 预发布版本。** 本版为钢结构 MiC 排程工作台的 W5 拟议交付。已发布 v1.0.1 及其附件保持。候选增加已核验计划等待反馈及单次调用独占的回放准备，保留原独立检查、业务判定和安全 STOP 通道。软件仍可能存在 bug 或未知问题。

## 变更及实际验证范围

- 初排显示等待；重排时保留上一已验证甘特及版本/源龄，直到当前任务独立核验通过。迟到、跨运行及终态消息不能切换旧候选。心跳、排程阶段与实际观测源龄分列。
- 计划引用失败时保留已接受的业务回执，引用恢复健康前禁写。STOP 发出、持久受理、保存及实际退出分列；UNKNOWN 恢复在原门内查询或恢复原身份。
- 回放只共享已检查的不可变记录，可变容器保持私有。每次预览独占后端种子、优先级及几何缓存；执行与因果审计走原几何。没有安装实验源码改写、公共模块替换或 W4 缓存。
- W3 四组 CPU 配对属于历史证据：提交至已核验投影配对中位减少 17.331061%，净回放减少 26.501367%。数字绑定较早隔离候选，W5 没有新的四组性能估计或工业资格。

最终候选通过 scripts/check.py 的源码 1299 项及隔离 wheel 1299 项完整测试；原发布 1,277 个测试身份全部保留，新增 22 个。前端 23 项通过。隔离重建的 HTML、JavaScript、CSS 原字节一致；source map 映射与源列表一致，仅两份内嵌源文本存在 CRLF/LF 差别。候选保留原 W2a map，并记录该差异。

固定 L1 v2 计划和解压证明的 SHA-256 与原件精确一致，完整 Python 回退也生成同一计划及证明。11 项所有权/回退测试、12 项坏证据测试、两项发布保护以及原好件/四类坏件检查通过。便携 CPU/Qt 链保留 v1、独立核验后采用 v2，保存 STOPPED/COMPLETE，工作进程退出 0。只读及回退存档各显示 1,023 条已核验计划区间，真实 EXE 存档入口也正常关闭。受限环境中渲染器退出 49 的失败保留；成功 Qt 检查使用正常本机进程环境。

本机合成 Kit 链通过，库源码身份与便携候选一致：初排、独立核验、一次仅修改仿真数据的 ORDER_UPDATE、v2 待核时保留 v1、新版核验切图、原安全 STOP、STOPPED/COMPLETE 保存及原生进程实际退出 0。已安装的 Isaac Sim 6.1 新建私有 USD 仿真。启动保持 900 s 仿真墙钟预算，并单列两小时测试窗口和 45 分钟退出收尾余量。保存的 v2 会话以只读方式重开并呈现 1,023 条独立核验的当前计划区间。这是一次原生功能运行，没有 Kit 配对计时数据，也不构成工业提速资格。

## 使用与复跑

完整解压拟议 Windows ZIP，保持 HRC-Workbench.exe 与 app 相邻后启动。包内含 Python 3.12.13、Qt、OR-Tools 和前端。在“启动配置”启动单个 SR-W1 CPU 产品。改单期间保留上一已验证计划，待新版独立核验后切换。使用“安全停止”，等待持久受理、保存完成与实际工作进程退出。保存会话以只读方式打开。

可选原生三维须配置另行安装的 Isaac Sim 6.1、PowerShell 7 及纯 ASCII 结果目录。受测入口是私有会话中的本机合成 USD 仿真，不连接真实设备或外部业务系统。异机及其他版本仍待验证。

源码根目录采用锁定环境及 Python 3.12.13，执行 `python scripts/check.py`；入口运行源码检查、构建发行物、建立隔离 wheel 环境，再完整运行测试。前端在 desktop/p051/web 使用既有锁执行 `npm ci`、`npm test`、`npm run build`。报告重建见 [reports/w5/BUILD.md](../../reports/w5/BUILD.md)。

启动前设置 `P051_PREVIEW_REUSE=0` 使用原完整复制、原几何和无种子复用的 Python 准备路径；`P051_WAIT_FEEDBACK=0` 隐藏新增等待反馈。核验、写保护及 STOP 继续生效。移除变量并启动新会话即可恢复默认。
