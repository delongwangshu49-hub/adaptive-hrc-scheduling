# v1.0.0 — 工作台第一正式版

[English](v1.0.0.md) · [简体中文](v1.0.0.zh-CN.md) · [下载入口](https://github.com/delongwangshu49-hub/adaptive-hrc-scheduling/releases/tag/v1.0.0)

本版汇集 Windows 便携工作台、中英双语审定报告，以及既有钢结构 MiC 生产案例。本机已验证的主要功能可用，仍可能存在 bug 或未知问题。后续正在评估成熟方案、规划响应速度和现有缺口的改进。

`v1.0.0` 是首次正式应用交付的版本号；包内 Python 库保留原有 `0.1.0` 元数据。既有研究结果和阶段标签保持。

## 下载与启动

从发布页下载 `HRC-Workbench-Windows-x64.zip`，完整解压后双击 `HRC-Workbench.exe`，保留同级 `app` 文件夹。ZIP 为 340,032,822 字节，含 8,524 个文件。启动器为未签名构建，使用 Windows .NET Framework 4.x。

包内包含 Python 3.12.13、PySide6 6.12.0、Qt WebEngine 6.140.0、OR-Tools 9.15.6755、甘特前端、SR-W1/SR-W2 生产输入和只读 CPU 存档。CPU 模式无需另外安装 Python 或 Isaac Sim。

1. 打开 **启动配置**，运行默认单产品 SR-W1 CPU 案例。
2. 初排和独立甘特回放各自需要等待。通过 **便携设置与示例** 打开随包存档或选择结果目录。
3. 使用 **安全停止** 结束会话，等工作进程退出。通过 **打开会话** 查看已有会话。

结果默认位于 `%LOCALAPPDATA%\HRCWorkbench\runs`；启动诊断为 `%LOCALAPPDATA%\HRCWorkbench\startup.log`，工作进程日志位于对应运行目录。[反馈问题](https://github.com/delongwangshu49-hub/adaptive-hrc-scheduling/issues)时，请附版本、复现步骤、所选后端和相关日志。

### 可选原生三维

单独安装 Isaac Sim 6.1 和 PowerShell 7。在便携设置中选择包含 `python.bat` 和 `VERSION` 的 Isaac 根目录，将结果目录设为纯 ASCII 的可写路径，例如 `C:\HRC\runs`，再选择 **Isaac / Kit**。本机构建验证使用 **6.1.0-rc.26**，其他机器和版本仍需验证。

本机曾在中文结果路径下出现原生截图失败。启动器会在 Kit 启动前检查该条件，并将 Kit 渲染缓存放到所选结果目录。CPU 和存档支持中文路径。NVIDIA 运行时与资产由用户另行获取。

## 源码与重建

入口为 [`desktop/p051/portable`](../../desktop/p051/portable)。构建需要 Windows x64、PowerShell 7、uv 0.12.3、Node/npm 及 Windows .NET Framework x64 C# 编译器。本次记录使用 PowerShell 7.6.5 和 Node 24.20.0。Python 与 npm 依赖使用已有锁文件，安装到独立构建目录，并在那里重建前端。

```powershell
& ./desktop/p051/portable/build.ps1 `
  -BuildDirectory 'C:/HRC/build-v1' `
  -ArchiveDirectory 'C:/HRC/verified-cpu-session'
```

请使用新的构建目录和已验证的 CPU 会话。随包存档是用于查看的只读子集，完整生产证据另行保留。源码仓库中的旧前端 `dist` 作为历史产物保持；README 的源码启动步骤会重建当前前端。

项目代码采用 [MIT](../../LICENSE)，随包组件各自的[许可与源码入口](../../desktop/p051/portable/THIRD-PARTY.md)也在 ZIP 中提供。
