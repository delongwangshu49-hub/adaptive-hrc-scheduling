## 实现与证据

[最小脚本](../../scripts/isaac_smoke.py) 在实际 6.1.0-rc.26 安装中使用 SimulationApp 与新 Core API，建立代码生成的地面和分离立方体。三个独立进程分别运行 1、16、64 个刚体，每次三轮、每轮 240 步；2,160 次物理回调、位姿/速度读取、下落落地、重置与完整退出均满足检查。

所有重置和重复轨迹最大分量误差为 0。独立验证器重读日志，连同 CPU 和命令行负向检查共 103 项通过。CPU 统一入口继续覆盖静态/格式、安装、构建与独立 wheel 自检；不会导入 Isaac 或执行 GPU 场景。脚本摘要与各次运行副本一致。

资源数字、计时区间、警告和复验命令详见 [运行验证](../validation/runtime.md)。承载证据只覆盖单进程 64 个以内此类分离刚体、CPU PhysX、短时无逐帧渲染测量；不是最大容量、通用兼容性或完整生产闭环验证。首轮内存开销高，未测长时/多实例、机器人或传感器。

本地监督工具首次路径解析失败、初始旧 API 目录查找失败及修正记录均保留；真实场景运行没有断言失败或超时。既有步骤证据摘要、提交、标签保持不变。本地包另外检查确切文件集合、完整差异、编码、链接、公开边界、记录编号和封后内容摘要。

S02 的实际发布/两平台 CI 和随后 17 项完成性复核按 LOG015 / LOG016 补录。零测试误报猜测已被排除，不记录为真实缺陷。负责人授权范围和验收职责由负责人承担；脚本、文档和实际本地检查由 AI 助手完成，不虚构负责人手工编码或已验收。
