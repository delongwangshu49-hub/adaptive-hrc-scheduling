r1 在真实 Isaac 安装中完成 1、16、64 个基础刚体的三轮推进、回调、状态读取、重置与退出。实际批准、提交、标签与两平台 CPU CI 均已核验，见 [LOG018](../../PROGRESS_LOG.md#2026年10月1日-s03-r1-回执补录)。发布后 53 项完成性复核通过，全新发布副本的 CPU 入口通过。

审阅复现两项 P2：整轮回调总数会漏检一次遗漏与一次重复的组合；本地监督器在资源采样异常时未保证清理子进程与写入最终结果。原三次正常运行没有因此被判为失败；故障注入证明检查存在盲点，不证明旧运行发生了该异常。原证据、提交与标签不改写。

## r2 修复与证据

- [场景脚本](../../scripts/isaac_smoke.py) 每次推进后检查恰好一次回调，核对实际 physics_step、simulation_time 和 dt；日志保留真实步号及失败前采集的数据。
- [CPU 回归](../../tests/test_isaac_callbacks.py) 新增五项：正常回调、遗漏与重复不能抵消、错误步号、错误时间、错误 dt；其中覆盖非有限时间值。测试不导入 Isaac，与两项安装自检合计七项，由既有统一入口自动执行。
- 新本地监督工具记录采样异常，在退出路径清理所启动的进程树并回收父进程；异常和清理失败均记为失败，结果使用排他写入。旧工具保留为历史原件。
- 最终源码分别在 1、16、64 个刚体上执行三轮 240 步，共 2,160 条回调；独立重读核对实际步号、时间、形状、有限数、重置、下落、落地与重复轨迹，三个进程均正常退出。
- 两次真实注入分别为“漏第 10 次、重复第 11 次”和“单独重复第 11 次”；分别在第 10、11 步被拒绝，场景 FAILED 且正常关闭。前者在遗漏处立即终止，因此不继续执行后续重复动作。
- 该安装包装器在场景失败时仍可能返回 0。新监督器联合检查场景 PASSED、closed=true、退出 0 和无超时，缺失或损坏场景结果也拒绝通过；不将退出 0 当作成功的充分条件。公开复验命令同样检查场景结果。
- 本地监督器 12 项受控回归通过，覆盖采样超时、采样命令缺失/非零、中断、总时限、正常退出、启动失败、排他结果写入，以及退出 0 时场景缺失/失败/未关闭/成功的四种结果；测试父子进程均已清理。

独立结果重读与统一 CPU 入口合计 93 项检查通过。前期候选与最终源码的差别、负向注入原始结果及工具准备失败记录均保留，最终验收绑定最终源码摘要。完整证据、机器配置与本地工具不公开。实施与验证由 AI 助手在授权范围内完成；没有把负责人授权写成人工编码或本次验收。

实测资源口径及限制见 [运行验证](../validation/runtime.md)。承载范围保持单进程、基础分离刚体、CPU PhysX、短时无逐帧渲染；未验证机器人、传感器、长时负载或生产闭环。r1 资源表保留原值，修复复验不用于扩大容量或推导性能收益。
