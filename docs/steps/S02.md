## 实际实现

统一入口 `uv run --locked --no-editable python scripts/check.py` 检查固定 Python、锁文件、Ruff 静态规则和格式、两项安装自检、依赖一致性，以及从 sdist 构建 wheel 后在全新环境的安装自检。Ruff 0.16.9 是唯一开发依赖；运行依赖仍为空，包版本维持 0.1.0。

GitHub Actions 候选使用 ubuntu-24.04 / windows-2025 矩阵、固定 Action 提交 SHA、uv 0.12.3、PowerShell 7、只读权限和超时限制，运行同一入口。没有安装 Isaac 或执行 GPU 检查。具体运行、贡献与失败处理见 [开发说明](../development.md)。负责人授权范围与验收决定由负责人承担；代码、文档与本地检查由 AI 助手在授权范围内完成。

同时按真实凭证补录 S01 r2 的批准和发布回执，保留历史封存记录；没有改写原提交、标签、审批材料或旧环境检查工具。
