## 检查与限制

18 项环境命令成功，开发环境、独立源文件副本的非 editable 安装及独立 wheel 安装均通过同一组两项自检；116 项快照检查通过。检查覆盖以下范围：

1. 固定版本的项目环境安装与最小 JSON 入口；两项 unittest 自检。
2. 仅复制候选源文件到独立目录，重建全新环境；禁用包缓存和 editable 安装；从仓库外、隔离模式运行已安装包；检查依赖一致性及没有 Isaac 包混入。
3. 构建 sdist 和 wheel，检查归档仅含声明源文件和必要元数据；将 wheel 安装到另一个全新环境，再运行同一安装自检。此项不上传分发包。
4. 锁文件与声明一致且重建前后未变；实际解释器版本与固定版本相符。工具引导安装与解释器探针的完整日志只留本地。
5. 公开文件 UTF-8 无 BOM、LF、链接、记录编号、隐私模式和完整差异检查；十二文件范围及完整候选树可核对；原 S00 本地证据摘要不变。

限制：只验证本步安装与复现能力，不验证任何生产或研究功能。跨平台未测；未从零下载 Python 二进制；Isaac RC 安装的 GPU、场景与闭环仍待 S03；没有 CI，不能写作 CI 通过。公开模式扫描不替代负责人全文审阅。
